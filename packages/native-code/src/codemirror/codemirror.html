native-codemirror

Shared CodeMirror 6 integration layer for the NativeUI ecosystem. Provides a dark theme, syntax highlighting, base extensions (keymaps, history, brackets, autocomplete, line numbers), and a createEditorView() factory.

One-line factory — creates a themed editor with all base extensions.

Declarative custom element wrapping CodeMirror 6. Supports value, placeholder, readonly, disabled, line-numbers, line-wrapping, and tab-size attributes. Set the extensions property for language modes.
