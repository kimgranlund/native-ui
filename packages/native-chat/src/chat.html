Message Feed

n-chat-feed coordinates a scrollable thread. n-chat-messages groups messages from the same sender. n-chat-message renders individual bubbles with action toolbars.

Conversation thread
Multi-message group 
<n-chat-feed auto-scroll>
  <n-chat-messages role="assistant" sender="Assistant">
    <n-chat-avatar icon="chat-dots"></n-chat-avatar>
    <n-chat-message role="assistant" message-id="msg-1">
      <n-chat-message-text>Hello!</n-chat-message-text>
    </n-chat-message>
  </n-chat-messages>

  <n-chat-messages role="user" sender="Kim">
    <n-chat-avatar name="Kim Granlund"></n-chat-avatar>
    <n-chat-message role="user" message-id="msg-2">
      <n-chat-message-text format="plain">How does this work?</n-chat-message-text>
    </n-chat-message>
  </n-chat-messages>
</n-chat-feed>

Avatar

n-chat-avatar renders an image, icon, or initials based on attributes. Fallback chain: src → icon → name initials → default user icon.

Icon
Initials (1 word)
Initials (2 words)
Default (no attrs)

<n-chat-avatar name="Kim Granlund"></n-chat-avatar>
<n-chat-avatar src="/avatars/kim.jpg" name="Kim"></n-chat-avatar>

Message Text

n-chat-message-text renders markdown to sanitized HTML. Supports headings, lists, code fences, inline formatting, links, and blockquotes.

Markdown (default)
Plain text 
<n-chat-message-text>**Bold**, *italic*, `code`</n-chat-message-text>
<n-chat-message-text format="plain">No formatting applied.</n-chat-message-text>

<!-- Or set via property: -->
<script>
  el.content = '## Heading\n\nParagraph with **bold**.';
</script>

Activity Indicator

n-chat-message-activity shows streaming status with elapsed timer. Supports typing, thinking, and tool-use types. Add expandable for collapsible reasoning trace.

Typing (active)
Thinking (active)
Tool use (active)
Expandable reasoning trace (click to toggle) 
Step 1: Analyzing the query...
Step 2: Searching knowledge base...
Step 3: Formulating response...
Step 4: Applying formatting rules...
Inactive (completed)

<n-chat-message-activity type="thinking" active></n-chat-message-activity>
<n-chat-message-activity type="tool-use" active></n-chat-message-activity>

<!-- With expandable reasoning trace -->
<n-chat-message-activity type="thinking" active expandable>
  <pre>Step 1: Analyzing...</pre>
</n-chat-message-activity>

Seed Chips

n-chat-message-seed renders pre-seeded response options as clickable chips. Fires native:seed-select with { value, label }.

Starter prompts
Disabled 
<n-chat-message-seed></n-chat-message-seed>
<script>
  el.options = [
    { value: 'explain', label: 'Explain this code' },
    { value: 'refactor', label: 'Suggest refactoring' },
    { value: 'test', label: 'Write tests' },
  ];
</script>

Structured Input

n-chat-input-structured renders a multi-choice card. Supports single and multi selection modes. Fires native:structured-submit with { question, selections }.

Single select
Multi select 
<n-chat-input-structured
  question="What language do you prefer?"
  type="single">
</n-chat-input-structured>
<script>
  el.options = [
    { value: 'ts', label: 'TypeScript' },
    { value: 'js', label: 'JavaScript' },
    { value: 'py', label: 'Python' },
  ];
</script>

GenUI (Schema → DOM)

n-chat-message-genui renders UI from a schema tree. Validates against a forbidden tag list. Supports inline and lightbox modes.

Inline mode
Lightbox mode 
<n-chat-message-genui mode="inline"></n-chat-message-genui>
<script>
  el.schema = {
    tag: 'n-card',
    children: [
      { tag: 'p', text: 'Generated UI card' },
      { tag: 'n-button', text: 'Action',
        attributes: { variant: 'primary', intent: 'accent' } },
    ]
  };
</script>
