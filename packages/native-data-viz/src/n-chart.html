<n-chart>

SVG charting component with reactive store, auto-detected scales, crosshair + tooltip interactions, and OKLCH color palette. Types: line, bar, scatter, sparkline. Three usage tiers: widget (sparklines), card (compact panels), and dashboard (full axes + legend + tooltips).
