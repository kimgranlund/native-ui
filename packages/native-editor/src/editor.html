<native-editor>

Markdown content editor with live preview and source modes. Built on CodeMirror 6, renders a toolbar with formatting commands and an Obsidian-style live preview.

Default — Live Preview Mode

<native-editor>
  <script type="text/markdown">
# Hello World

This is a **bold** and *italic* text.
  </script>
</native-editor>

Source Mode

<native-editor mode="source">
  <script type="text/markdown">
# Source Mode
Raw markdown without decorations.
  </script>
</native-editor>

Placeholder

<native-editor placeholder="Start typing your markdown here..."></native-editor>

Read-only

<native-editor readonly>
  <script type="text/markdown">
# Read-only Document
Content is not editable.
  </script>
</native-editor>

Disabled

<native-editor disabled>...</native-editor>

Form Integration

Submit Reset 
<form>
  <native-editor name="content">...</native-editor>
  <n-button type="submit" variant="primary">Submit</n-button>
  <n-button type="reset" variant="secondary">Reset</n-button>
</form>

<script>
  form.addEventListener('submit', (e) => {
    e.preventDefault();
    const data = new FormData(form);
    console.log(data.get('content'));
  });
</script>

Change Events

<native-editor id="editor">...</native-editor>

<script>
  editor.addEventListener('change', (e) => {
    console.log(e.detail.value.length, 'chars');
  });
</script>

Data Gateway — Load from URL

Save Reload 
<native-editor id="editor" src="/api/content"></native-editor>

<script>
  editor.addEventListener('dirty-change', (e) => {
    saveBtn.disabled = !e.detail.dirty;
  });
  saveBtn.addEventListener('native:press', () => editor.save());
  reloadBtn.addEventListener('native:press', () => editor.reload());
</script>
