API

Provider Usage

AttributeTypeDefaultDescription
data-trait-magnetizable-selector string :scope > * CSS selector for draggable items within host.
data-trait-magnetizable-threshold number 20 Snap threshold distance in px.
data-trait-magnetizable-grid-size number 0 Snap-to-grid size in px. 0 means snap to elements only.
data-trait-magnetizable-strength number 1 Snap strength 0-1. 1 is instant snap, lower values ease toward the snap point.
data-trait-magnetizable-guides boolean true Show guide lines when snapping.
data-trait-magnetizable-guide-color string var(--n-color-accent-500) Guide line color.
data-trait-magnetizable-snap-to-edges boolean true Enable snap to container edges.
data-trait-magnetizable-snap-to-siblings boolean true Enable snap to sibling element edges and centers.
data-trait-magnetizable-disabled boolean false Disable the magnet controller.

Events

EventDetailDescription
native:magnet-snap { item, x, y, snappedTo, axis } Fired during drag when an item snaps. snappedTo is the snap type (e.g. edge/center). axis is "x", "y", or "both".
native:magnet-drop { item, x, y } Fired when the item is released after dragging.

CSS

SelectorDescription
[magnet-snapping] Present on a dragged item while it is snapping to an edge, sibling, or grid position.
