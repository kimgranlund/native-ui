CSS Inspectable

Hold Option and hover to preview element outlines, click to explode layers in 3D space with interactive tilt. Click outside or press Escape to close. Like Firefox's old 3D DOM inspector.

Provider (n-controller)

Wrap elements with <n-controller traits="css-inspectable"> to make them inspectable. Hover to preview, click to explode.

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-css-inspectable-depth number 16 Z-spacing between exploded layers in px.
data-trait-css-inspectable-scale number 0.85 Scale factor during inspection.
data-trait-css-inspectable-perspective number 1200 CSS perspective distance in px.
data-trait-css-inspectable-max-tilt number 60 Maximum mouse tilt angle in degrees.
data-trait-css-inspectable-tilt-radius number 384 Mouse distance from center for max tilt in px.
data-trait-css-inspectable-labels boolean true Show tag/id/class labels on layers via data-inspect-label.
data-trait-css-inspectable-recursive boolean true Walk all descendants recursively, not just direct children.
data-trait-css-inspectable-pick boolean false Enable pick mode: Alt+hover highlights descendants, Alt+click picks the inspection target.
data-trait-css-inspectable-disabled boolean false Disable the inspector.

Events

EventDetailDescription
native:inspect { active, layers } Fired when inspection activates or deactivates. active is a boolean, layers is the number of exploded layers.

CSS

SelectorDescription
[inspecting] Present on the host while 3D inspection is active.
[inspect-ready] Present when Alt is held and the element is ready for inspection (crosshair cursor).
[inspect-layer] Set on each exploded child element during inspection.
[inspect-hover] Set on the hovered layer during inspection.
[inspect-selected] Set on the clicked/selected layer during inspection.
[data-inspect-label] Set on layers when labels: true. Value is the tag/id/class string for CSS ::after display.
--inspect-tilt-y CSS custom property with current Y tilt angle (for label counter-rotation).
--inspect-tilt-x CSS custom property with current X tilt angle (for label counter-rotation).
