Backtick Wrap

Watches for paired backtick delimiters in a contenteditable input. When the user types a closing ` that matches an opening `, the text between them is wrapped in a styled <code> element. Also wraps selected text when ` is typed with an active selection.

Basic Backtick Wrap

Type `hello` — when you type the closing backtick, "hello" becomes an inline <code> element. You can also select text and press ` to wrap the selection. 

import { BacktickWrapController } from '@nonoun/native-traits';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

const backtick = new BacktickWrapController(wrapper, {
  input: textarea,
});

wrapper.addEventListener('native:backtick-wrap', (e) => {
  console.log('Wrapped:', e.detail.text);
});

Combined: Slash + Mention + Backtick

All three text command controllers on one input. Type / for slash commands, @ for mentions, and `code` for inline code. All work independently without conflict. 

// All three controllers on the same input
const slash = new SlashCommandController(wrapper, { input, commands });
const mention = new MentionController(wrapper, { input, items });
const backtick = new BacktickWrapController(wrapper, { input });

API

Constructor Options (BacktickWrapOptions)

Property Type Default Description input HTMLElement --- The input element to monitor. disabled boolean false Disable the controller without destroying it.

Events

Event Detail Description native:backtick-wrap { text, element } Fired when text is wrapped in a <code> element. text is the wrapped string, element is the created <code> node.

Behavior

Trigger Action Closing ` after opening ` Wraps text between the backtick pair in a <code> element. Single-line only (does not cross newlines). ` with text selected Wraps the selected text in a <code> element. Empty backtick pair `` No-op — types normally. Cmd/Ctrl/Alt+` Ignored — modifier combinations pass through.
