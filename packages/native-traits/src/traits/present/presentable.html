Presentable

Shows content in a full-viewport dialog overlay. The host element is moved into a modal <dialog> at its current DOM position and promoted to the top layer. Dismiss via close button, Escape, or backdrop click.

Basic Present

Click the card to present it full-viewport. Press Escape, click the backdrop, or use the close button to dismiss.

Click to Present

This card will expand to fill the viewport in a modal overlay.

<script>
  import { PresentController } from '@nonoun/native-ui';

  const ctrl = new PresentController(card);
  card.addEventListener('click', () => ctrl.present());
  // ctrl.dismiss();
  // ctrl.toggle();
</script>

No Close Button

Presented without the close button. Dismiss via Escape or backdrop click only. Uses closeButton: false.

No Close Button

Press Escape or click the backdrop to dismiss.

const ctrl = new PresentController(card, {
  closeButton: false,
});

Custom Inset

Controls the margin from viewport edges with the inset option. This example uses a larger 4rem inset for more breathing room.

Wide Inset (4rem)

Notice the extra margin from viewport edges.

const ctrl = new PresentController(card, {
  inset: '4rem',
});

Button Trigger

Use a button to trigger the presentation instead of clicking the card directly. Demonstrates the toggle() method.

Present Content

Toggled Content

This was triggered by a button using toggle().

btn.addEventListener('click', () => ctrl.toggle());

Provider Usage (n-controller)

Use with <n-controller traits="presentable"> for declarative setup. Click the card to present.

Declarative Present

Using n-controller with the presentable trait.

 
<n-controller traits="presentable">
  <div class="present-card">...</div>
</n-controller>

API

Constructor Options

OptionTypeDefaultDescription
inset string '2rem' Safety margin from viewport edges (CSS length value).
closeButton boolean true Show a close button in the top-right corner of the overlay.

Provider Usage

AttributeTypeDefaultDescription
data-trait-presentable-inset string '2rem' Viewport edge margin.
data-trait-presentable-close-button boolean true Show close button. Set to "false" to hide.

Methods

MethodReturnsDescription
present() void Wrap host in a dialog and show as a modal overlay.
dismiss() void Close the overlay and restore the host to its original position.
toggle() void Toggle between present and dismiss.
destroy() void Dismiss if open and clean up.

Events

EventBubblesDescription
native:present Yes Dispatched after the dialog opens and content is presented.
native:dismiss Yes Dispatched after the dialog closes and host is restored.

CSS

SelectorDescription
[presented] Present on the host element while the overlay is open. Use for fullscreen styling.
dialog[data-present]::backdrop The dialog backdrop. Default: rgba(0,0,0,0.75).

Keyboard

KeyAction
Escape Dismiss the overlay and restore the host.
