Link Paste

Select text in a contenteditable input, then paste a URL from your clipboard. The selected text is converted into a styled <a> hyperlink pointing to the pasted URL. If no text is selected, the paste proceeds normally.

Basic Link Paste

Type some text, select a word, then paste a URL (e.g. https://example.com). The selected word becomes a hyperlink. If nothing is selected, paste behaves normally. 

import { LinkPasteController } from '@nonoun/native-traits';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

const linkPaste = new LinkPasteController(wrapper, {
  input: textarea,
});

wrapper.addEventListener('native:link-paste', (e) => {
  console.log('Linked:', e.detail.text, '→', e.detail.url);
});

Combined: All Text Commands

All four text command controllers on one input. Type / for slash commands, @ for mentions, `code` for inline code, and select text + paste URL for links. All work independently without conflict. 

// All four controllers on the same input
const slash = new SlashCommandController(wrapper, { input, commands });
const mention = new MentionController(wrapper, { input, items });
const backtick = new BacktickWrapController(wrapper, { input });
const linkPaste = new LinkPasteController(wrapper, { input });

API

Constructor Options (LinkPasteOptions)

Property Type Default Description input HTMLElement --- The input element to monitor. disabled boolean false Disable the controller without destroying it.

Events

Event Detail Description native:link-paste { url, text, element } Fired when selected text is converted to a hyperlink. url is the pasted URL, text is the original selected text, element is the created <a> node.

Behavior

Trigger Action Paste URL with text selected Wraps selected text in <a href="..."> pointing to the pasted URL. Opens in new tab (target="_blank"). Paste URL with no selection No-op — paste proceeds normally. Paste non-URL with selection No-op — paste proceeds normally. Accepted URL formats https://, http://, ftp://, // (protocol-relative)
