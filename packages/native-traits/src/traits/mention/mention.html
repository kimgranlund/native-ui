Mention

Detects @ anywhere in an input (preceded by whitespace or at text start), shows a caret-anchored mention listbox popover, filters by query, and inserts a styled mention tag on selection. Uses the same TextTriggerController base class as slash commands. Works with <n-textarea> and <n-input>.

Basic Mentions

Type @ in the textarea to see the mention list. Arrow keys navigate, Enter selects, Escape closes. An accent-colored mention tag is inserted on selection. Works mid-text — try typing some text then @. 

import { MentionController } from '@nonoun/native-traits';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

const mention = new MentionController(wrapper, {
  input: textarea,
  items: [
    { value: 'kim', label: 'Kim Granlund', description: 'Designer' },
    { value: 'alex', label: 'Alex Chen', description: 'Engineer' },
    { value: 'sam', label: 'Sam Rivera', description: 'Product Manager' },
  ],
});

wrapper.addEventListener('native:mention-select', (e) => {
  console.log('Mentioned:', e.detail.command);
});

With n-input

Same pattern using <n-input> for single-line input. Type @ to trigger the mention popover.

Combined: Slash + Mention

Multiple TextTriggerController instances on the same input. Type / for slash commands or @ for mentions — each triggers its own popover independently. 

import { SlashCommandController } from '@nonoun/native-traits';
import { MentionController } from '@nonoun/native-traits';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

// Both controllers on the same input — no conflict
const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: [{ value: 'help', label: 'Help' }, ...],
});
const mention = new MentionController(wrapper, {
  input: textarea,
  items: [{ value: 'kim', label: 'Kim Granlund' }, ...],
});

wrapper.addEventListener('native:slash-select', (e) => { ... });
wrapper.addEventListener('native:mention-select', (e) => { ... });

API

Constructor Options (MentionOptions)

Property Type Description input HTMLElement The input element to monitor (n-textarea, n-input, or any element dispatching native:input). items MentionItem[] Array of mentionable items to display in the popover.

MentionItem Interface

Property Type Required Description value string Yes Unique identifier (e.g. user ID). label string Yes Display name shown in the popover and in the inserted tag. description string No Optional description (used for filtering and title attribute). avatar string No Optional avatar URL — renders an n-avatar in the listbox option. action 'tag' | 'insert' | 'event' No Behavior on selection. Defaults to 'tag' (accent-colored mention pill).

Events

Event Detail Description native:mention-query { query, commands } Fired on host when typing after @. query is the text after @. commands is the filtered array of matching items. native:mention-select { command, action } Fired on host when a mention is selected (Enter or click). command is the full MentionItem object.

Keyboard

Key Action ArrowDown / ArrowUp Navigate mention list Enter Select active mention Tab Select closest match (when query has 2+ characters) Escape Close popover
