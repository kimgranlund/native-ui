Collapsible

Composable trait for animated show/hide with smooth height transitions. Dispatches native:expand and native:collapse events.

Basic Toggle

Toggle Content

This content smoothly animates open and closed using the Collapsible trait.

The height transition is calculated dynamically from the content's natural scroll height.

 
<!-- Declarative: n-controller with collapsible trait -->
<n-controller traits="collapsible">
  <div id="my-section">
    <p>Collapsible content here</p>
  </div>
</n-controller>

<script>
  // Toggle programmatically
  const el = document.getElementById('my-section');
  el.getTraitController('collapsible').toggle();

  // Listen for events
  el.addEventListener('native:expand', () => console.log('Expanded'));
  el.addEventListener('native:collapse', () => console.log('Collapsed'));
</script>

Initially Collapsed

Expand

I was hidden on page load. Click "Expand" to reveal me with a smooth animation.

 
<!-- Start collapsed with the collapsed attribute -->
<n-controller traits="collapsible">
  <div collapsed>
    <p>Hidden on page load</p>
  </div>
</n-controller>

<script>
  // Expand/collapse individually
  const ctrl = el.getTraitController('collapsible');
  if (ctrl.collapsed) ctrl.expand();
  else ctrl.collapse();
</script>

Custom Duration (500ms)

Toggle Slow

This section uses a custom data-trait-collapsible-duration="500" for a slower, more dramatic animation.

 
<!-- Custom animation duration (default: 200ms) -->
<n-controller traits="collapsible" data-trait-collapsible-duration="500">
  <div>
    <p>Slower 500ms animation</p>
  </div>
</n-controller>

<!-- Imperative: CollapsibleController -->
<script>
  import { CollapsibleController } from '@nonoun/native-ui';

  const ctrl = new CollapsibleController(hostElement, {
    duration: 500
  });
  ctrl.toggle();
</script>

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-collapsible-duration number 200 Animation duration in milliseconds.

Events

EventDetailDescription
native:expand none Fired after expand animation completes.
native:collapse none Fired after collapse animation completes.

CSS

SelectorDescription
[collapsed] Present on the element when collapsed. Set initially or by the controller after collapse animation.
