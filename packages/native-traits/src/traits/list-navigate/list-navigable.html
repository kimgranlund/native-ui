List Navigable

Coordinates roving focus, ARIA selection sync, and child select events for list-based components. Combines RovingFocusController with value tracking and automatic aria-selected/aria-checked synchronization.

Basic List Navigation

Use Arrow keys to navigate. Click or press Enter/Space to select. The list tracks selection via aria-selected and dispatches native:change.

<div role="listbox">
  <div role="option" value="apple">Apple</div>
  <div role="option" value="banana">Banana</div>
  <!-- ... -->
</div>

<script>
  const ctrl = new ListNavigateController(host, {
    itemSelector: ':scope > [role="option"]',
    orientation: 'vertical',
  });
  host.addEventListener('native:change', (e) => {
    console.log(e.detail.value, e.detail.label);
  });
</script>

API

Constructor Options

OptionTypeDefaultDescription
itemSelector string :scope > [role] CSS selector for navigable items within the host.
ariaAttr 'aria-selected' | 'aria-checked' | 'aria-current' 'aria-selected' ARIA attribute to sync with the current selection.
autoSync boolean true Automatically sync ARIA attributes on children when selection changes.
orientation 'horizontal' | 'vertical' | 'both' 'vertical' Keyboard navigation direction.
wrap boolean true Wrap focus from last to first (and vice versa).
disabled boolean false Disable keyboard navigation and selection.
onChildSelect (detail) => void set value + dispatch Override the default selection handler. Receives { value, label }.
addEffect (fn) => void - Required for auto ARIA sync. Connects to host's reactive effect system.
deferChildren (fn) => void - Required for auto ARIA sync. Defers until children are available.

Signals

SignalTypeDescription
listValue Signal<string | null> The currently selected value. Null when nothing is selected.

Events

EventDetailDescription
native:change { value: string, label: string } Dispatched when a child item is selected. Bubbles and is cancelable.
native:select { value: string, label: string } Listened on host. Typically dispatched by child items when clicked or activated.

Keyboard

KeyAction
ArrowDown / ArrowRight Move focus to the next item (direction depends on orientation).
ArrowUp / ArrowLeft Move focus to the previous item.
Home Move focus to the first item.
End Move focus to the last item.

CSS

SelectorDescription
[aria-selected="true"] The currently selected item (when using default ariaAttr).
[aria-checked="true"] The currently checked item (when ariaAttr is 'aria-checked').
[tabindex="0"] The focusable item in the roving focus group.
[tabindex="-1"] Non-focusable items in the roving focus group.
