Copyable

One-click copy-to-clipboard with visual confirmation feedback. Sets the [copied] attribute during the feedback window and dispatches native:copy.

Basic Copy Injection

traits="copyable pressable" on a minimal NativeElement shell. Click triggers copy via native:press. The [copied] attribute provides visual feedback for 2 seconds.

npm install native-ui Copy 
<copy-demo traits="copyable pressable"
  data-trait-copyable-value="npm install native-ui">
  <span class="copy-label">npm install native-ui</span>
  <span class="copy-indicator">Copy</span>
</copy-demo>

// Minimal NativeElement shell
class CopyDemo extends NativeElement {}
define('copy-demo', CopyDemo);

// Wire native:press → copy
el.addEventListener('native:press', () => {
  el.getTraitController('copyable')?.copy();
});

Copy with Getter

The copyable adapter takes static value strings. For dynamic values (like timestamps), use CopyController directly with a getter function.

Copy current timestamp Copy 
import { CopyController } from '../../index.ts';

const el = document.querySelector('#getter-demo');
const copy = new CopyController(el, {
  value: () => new Date().toISOString(),
});

el.addEventListener('native:press', () => copy.copy());

Custom Duration (500ms) Injection

data-trait-copyable-feedback-duration="500" for quick feedback instead of the default 2000ms.

Quick feedback copy Copy 
<copy-demo traits="copyable pressable"
  data-trait-copyable-value="Quick feedback copy"
  data-trait-copyable-feedback-duration="500">
  <span class="copy-label">Quick feedback copy</span>

</copy-demo>

Provider Pattern Provider

<n-controller> applies copyable to a plain <div>. No NativeElement subclass needed for the target. The controller manages [copied] feedback; a click listener triggers copy().

npx create-native-ui@latest Copy 
<n-controller traits="copyable"
  data-trait-copyable-value="npx create-native-ui@latest">
  <div class="copy-card">
    <span class="copy-label">npx create-native-ui@latest</span>
    <span class="copy-indicator">Copy</span>
  </div>
</n-controller>

API

Adapter Options (data-trait-copyable-*)

AttributeTypeDefaultDescription
data-trait-copyable-value string '' The static string to copy. For dynamic values, use CopyController directly with a getter function.
data-trait-copyable-feedback-duration number 2000 Duration in milliseconds that the [copied] attribute remains set after a successful copy.

Controller Methods

MethodReturnsDescription
copy() Promise<void> Writes the value to the clipboard, sets [copied], and dispatches native:copy.

Events

EventDetailDescription
native:copy { value: string } Fired after a successful copy. detail.value contains the copied string.

CSS

SelectorDescription
[copied] Present on the element during the feedback window after a successful copy. Use for visual confirmation styling.
