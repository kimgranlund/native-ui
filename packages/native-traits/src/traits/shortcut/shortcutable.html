Shortcutable Trait

Keyboard shortcut controller with combo-string parsing, editable filtering, and conditional guards.

Global Shortcuts

These shortcuts fire from anywhere on the page. Try pressing them:

Cmd/Ctrl + K Search Shift + ? Help Escape Dismiss
Press a shortcut to see it logged here.

Scoped Shortcuts (click here to focus)

These only fire when this panel is focused. Click inside, then press:

Cmd/Ctrl + S Save Cmd/Ctrl + Z Undo
Focus this panel, then press a shortcut.

Allow Editable

This shortcut works inside the input field (allowEditable: true):

Cmd/Ctrl + Enter Submit
Focus the input, then press Cmd/Ctrl + Enter.

Declarative (n-controller)

Using <n-controller traits="shortcutable"> with JSON shortcuts attribute:

Ctrl + H Hello (declarative)
Press Ctrl+H to test the declarative adapter.

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-shortcutable-shortcuts JSON [] JSON array of shortcut bindings. Each object: { id, combo, allowEditable?, preventDefault?, stopPropagation? }.
data-trait-shortcutable-global boolean false Listen on document (capture phase) instead of the host element.

Combo Syntax

ModifierDescription
mod Meta on Mac, Ctrl on Windows/Linux. Example: "mod+k".
ctrl, meta, shift, alt Explicit modifier keys. Combine with +. Example: "ctrl+shift+s".

Events

EventDetailDescription
native:shortcut { id, combo } Fired on the host when a registered shortcut matches. id is the binding identifier, combo is the combo string.

CSS

SelectorDescription
No CSS attributes are set by this controller. Shortcut handling is purely event-driven.
