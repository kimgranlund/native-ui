A2A Tic-Tac-Toe

Two AI agents play Tic-Tac-Toe through the A2A (Agent-to-Agent) protocol. Each player gets its own A2UI surface — an independent rendering context where the agent writes board state as declarative components. The kernel converts these into live DOM. Pick any combination of Claude, ChatGPT, or Human for X and O. In simulation mode, a local minimax AI replaces API calls for instant play. Auto Play runs the full game; Next Move advances one turn at a time.
