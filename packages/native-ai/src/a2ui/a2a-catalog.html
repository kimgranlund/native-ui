A2A Catalog

Your app hosts two agents: a first-party assistant you built (full access) and a third-party plugin from an external vendor (sandboxed). The plugin can render text, buttons, and cards — but if it tries to render form inputs, toggles, or modals, the session layer strips those components before they reach the DOM. This is how you give agents UI access without giving them the keys to the kingdom.
