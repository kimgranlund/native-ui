A2A Ownership

Two agents collaborate on a landing page — a Design Agent handles layout and visuals, while a Copy Agent writes headlines and body text. Only one agent can write to the shared canvas at a time. The host app transfers ownership between them like passing a baton. If an agent tries to write without ownership, the session layer blocks it — no race conditions, no overwrites.
