Stamped Chat Panel (Gateway)

<native-chat-panel> stamps its own DOM (header, feed, footer, input) and handles the full send → stream → render lifecycle via the gateway attribute. Use gateway="mock" for simulated responses, or gateway="claude" for real Anthropic models.

Mock gateway (type and send)
Claude Haiku 4.5 (requires API key) 
<!-- Mock gateway — auto-stamps header, feed, footer, input -->
<native-chat-panel gateway="mock" gateway-url="mock" open>
</native-chat-panel>

<!-- Claude gateway (model + config set via JS) -->
<native-chat-panel
  id="panel"
  gateway="claude"
  gateway-url="/api/anthropic"
  model="claude-haiku-4-5"
  open></native-chat-panel>
<script>
  // Set key via Vite env: VITE_ANTHROPIC_API_KEY
  panel.gatewayConfig = {
    apiKey: import.meta.env?.VITE_ANTHROPIC_API_KEY,
    model: 'claude-haiku-4-5',
    maxTokens: 1024,
  };
  panel.models = [
    { value: 'claude-haiku-4-5', label: 'Claude Haiku 4.5' },
    { value: 'claude-sonnet-4-6', label: 'Claude Sonnet 4.6' },
    { value: 'gpt-5.2', label: 'GPT-5.2' },
    { value: 'gpt-5.3-codex', label: 'GPT-5.3 Codex' },
    { value: 'gpt-5.2-codex', label: 'GPT-5.2 Codex' },
  ];
</script>
