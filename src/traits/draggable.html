Draggable

Composable trait for drag-and-drop. Three modes: drop (outlines the target element), slot (shows a gap indicator between items for insertion), and preview (live DOM reordering). Set zoneSelector to enable cross-zone dragging (e.g., kanban boards). Ghost renders in the top layer via popover. Press Escape to cancel.

Drop Mode — Swap (Provider)

<n-controller> wraps a plain <div> and applies the draggable trait. Drop onto a target to swap positions.

<script>
  list.addEventListener('native:drop', (e) => {
    const { item, target } = e.detail;
    if (!target || target === item) return;
    const placeholder = document.createElement('div');
    item.before(placeholder);
    target.before(item);
    placeholder.replaceWith(target);
  });
</script>

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-draggable-selector string — CSS selector for draggable items within the host. Required.
data-trait-draggable-drop-zone-selector string '' CSS selector for drop zones. Defaults to selector items if empty.
data-trait-draggable-zone-selector string '' CSS selector for zone containers (e.g., kanban columns). When set, items can be dragged between zones. Drop events include sourceZone and targetZone.
data-trait-draggable-axis 'vertical' | 'horizontal' | 'both' 'both' Constrains hit-testing to one axis. Ghost always moves freely.
data-trait-draggable-mode 'drop' | 'slot' | 'preview' 'drop' drop: outlines hovered target. slot: shows gap indicator. preview: moves the real item in real time (no consumer reordering needed).
data-trait-draggable-disabled boolean false Disables all drag behavior when true.
data-trait-draggable-animate boolean true Enable view-transition animation for preview mode grid reordering. Set "false" to disable.

Events

EventDetailDescription
native:drag-start { item, index } Fired on first pointer move after pointerdown.
native:drag-move { item, x, y } Fired on every pointer move during drag.
native:drag-over drop: { item, target, index }
slot: { item, index, insertBefore } 		Fired when the pointer enters a drop zone or the slot position changes.
native:drop drop: { item, target, fromIndex, toIndex, sourceZone, targetZone }
slot: { item, fromIndex, toIndex, insertBefore, sourceZone, targetZone }
preview: { item, fromIndex, toIndex, sourceZone, targetZone } 		Fired on pointer up. sourceZone and targetZone are set when zoneSelector is configured (null otherwise).
native:drag-cancel { item } Fired when Escape is pressed or pointer is cancelled.

Attributes (set during drag)

AttributeSet onDescription
[dragging] Dragged item Present while the item is being dragged. Use for opacity/visibility.
[drag-over] Drop zone (drop mode) Present on the zone the pointer is currently over.
[drag-slot-before] Item (slot mode) The item immediately after the insertion gap.
[drag-slot-after] Item (slot mode) The item immediately before the insertion gap.
[drag-zone-active] Zone container Present on the zone the ghost is currently over (cross-zone mode only).

CSS

SelectorDescription
.drag-placeholder Gap indicator element inserted by slot mode. Style height/width, background, and margin to match your layout.
