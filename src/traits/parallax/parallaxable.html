API

Provider Usage

AttributeTypeDefaultDescription
data-trait-parallaxable-max-tilt number 15 Maximum tilt angle in degrees.
data-trait-parallaxable-perspective number 1000 CSS perspective in px.
data-trait-parallaxable-speed number 300 Transition speed when entering/leaving in ms.
data-trait-parallaxable-scale number 1.05 Scale factor on hover.
data-trait-parallaxable-glare boolean false Enable glare/shine gradient overlay.
data-trait-parallaxable-glare-opacity number 0.35 Maximum glare opacity (0-1).
data-trait-parallaxable-gyroscope boolean false Enable gyroscope input on mobile devices.
data-trait-parallaxable-disabled boolean false Disable the parallax controller.

Events

EventDetailDescription
native:parallax-move { tiltX, tiltY, percentX, percentY } Fired on every mouse move while hovering. tiltX/tiltY are angles in degrees. percentX/percentY are -1 to 1 normalized positions.

CSS

SelectorDescription
[parallax-active] Present on the element while the pointer is over it and tilt is active.
--parallax-tilt-x CSS custom property with current X tilt value (number, degrees).
--parallax-tilt-y CSS custom property with current Y tilt value (number, degrees).
--parallax-percent-x CSS custom property with normalized X position (-1 to 1). Useful for driving box-shadow offsets.
--parallax-percent-y CSS custom property with normalized Y position (-1 to 1). Useful for driving box-shadow offsets.
