Clippable

Keyboard clipboard operations (Ctrl/Cmd+C/X/V) for structured data. Composes with Selectable to copy/cut selected items.

Copy & Paste

Click to select items, then use keyboard shortcuts to copy. Focus the list first by clicking an item.

Ctrl/Cmd+C — Copy Shift+Click — Range select Ctrl/Cmd+A — Select all

Cut & Paste

Ctrl/Cmd+X marks items with [clip-cut] (dimmed). Ctrl/Cmd+V dispatches a paste event.

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-clippable-selector string '' CSS selector for clippable items. Keyboard shortcuts act on [selected] items within this selector.
data-trait-clippable-disabled boolean false Disables all clipboard operations when true.
data-trait-selectable-selector string '' CSS selector for selectable items (from the selectable trait).
data-trait-selectable-mode 'single' | 'multiple' 'multiple' Selection mode: single or multiple (from the selectable trait).

Controller Methods

MethodDescription
copy(items) Copy given items to system clipboard and dispatch native:clip-copy.
cut(items) Copy items and mark them with [clip-cut]. Dispatch native:clip-cut.
paste() Read from clipboard and dispatch native:clip-paste.
cancelCut() Remove [clip-cut] from all previously cut items.
serialize(items) Convert items to a string. Default: joins textContent with newlines.
deserialize(data) Convert clipboard string back to an array of strings. Default: splits by newline.

Events

EventDetailDescription
native:clip-copy { items, data } Fired after a copy operation. data is the serialized string.
native:clip-cut { items, data } Fired after a cut operation. Items are marked with [clip-cut].
native:clip-paste { data } Fired after reading from clipboard. Consumer handles insertion.
native:selection-change { selected, count } Fired when the selection changes (from the selectable trait).

CSS Attributes

AttributeSet onDescription
[selected] Selected items Present on items currently selected (from the selectable trait).
[clip-cut] Cut items Present on items that have been cut. Use for dimmed/dashed styling.
