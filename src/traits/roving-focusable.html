RovingFocusable

Composable trait for keyboard navigation within a group. Only one item has tabindex="0" at a time — arrow keys move focus between items, Home/End jump to first/last. Skips disabled items.

Vertical (Arrow Up/Down)

<n-controller> applies roving focus with vertical orientation. Tab into the toolbar, then use Up/Down arrows. The "Italic" item is disabled and skipped.

Code
 
<n-controller traits="roving-focusable"
  roving-focusable-selector=".tool-btn:not([disabled])"
  roving-focusable-orientation="vertical">
  <div>
    <div class="toolbar">
      <div class="tool-btn" role="button">Bold</div>
      <div class="tool-btn" role="button" disabled>Italic</div>
      <div class="tool-btn" role="button">Underline</div>
    </div>
  </div>
</n-controller>

Horizontal (Arrow Left/Right)

Horizontal orientation with wrap-around. Use Left/Right arrows to navigate. Focus wraps from last to first.

API

Provider Usage

AttributeTypeDefaultDescription
roving-focusable-selector string — CSS selector for focusable items. Exclude disabled items with :not([disabled]).
roving-focusable-orientation 'vertical' | 'horizontal' | 'both' 'both' Which arrow keys to respond to. 'vertical' = Up/Down, 'horizontal' = Left/Right.
roving-focusable-wrap boolean true Whether focus wraps from last to first (and vice versa).
roving-focusable-disabled boolean false Disables roving focus when "true".

Keyboard

KeyAction
Arrow Up/Down Move focus in vertical mode.
Arrow Left/Right Move focus in horizontal mode.
Home Move focus to first item.
End Move focus to last item.
