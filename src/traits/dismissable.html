Dismissable

Composable trait that manages a global layer stack. When enabled, clicking outside the element or pressing Escape dispatches a native:dismiss event. Only the topmost layer in the stack receives dismiss events.

Click Outside to Dismiss

Uses DismissController directly on a plain element. Call enable() to join the dismiss stack, disable() to leave.

Open Panel
This panel is dismissable. Click anywhere outside it or press Escape to close.

Clicking inside the panel will not dismiss it. 
import { DismissController } from '@nonoun/native-ui';

const panel = document.getElementById('panel');
const dismiss = new DismissController(panel);

function showPanel() {
  panel.removeAttribute('hidden');
  dismiss.enable();
}

function hidePanel() {
  dismiss.disable();
  panel.setAttribute('hidden', '');
}

panel.addEventListener('native:dismiss', () => hidePanel());

Nested Layers (Stack)

Open both panels. Only the topmost one receives dismiss events. After the top panel is dismissed, the bottom panel becomes the new top.

Open Panel A Open Panel B
Panel A — I'm the first layer.
Panel B — I'm on top of Panel A. 
<!-- Each panel has its own DismissController -->
const dismissA = new DismissController(panelA);
const dismissB = new DismissController(panelB);

// Open Panel A — joins dismiss stack
panelA.removeAttribute('hidden');
dismissA.enable();

// Open Panel B — becomes top of stack
panelB.removeAttribute('hidden');
dismissB.enable();

// Escape/click-outside dismisses B first, then A

Built-in: n-dialog

n-dialog uses Dismissable internally. Escape and backdrop click close the dialog automatically.

API

Methods

MethodDescription
enable() Pushes the element onto the global dismiss stack. Click-outside and Escape will fire native:dismiss on this element.
disable() Removes the element from the dismiss stack. No more dismiss events.
destroy() Removes from stack and cleans up. Call in teardown().

Events

EventDetailDescription
native:dismiss — Fired when click-outside or Escape occurs while this element is the topmost layer. Consumer handles hiding.
