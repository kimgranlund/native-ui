Resizable

Composable trait for drag-to-resize functionality. Configure axis constraints, min/max sizes, and handle selectors. Dispatches native:resize-start, native:resize-move, and native:resize-end events. Press Escape to cancel.

Horizontal Resize

Drag the right edge to resize horizontally.
Width: 300px
<n-controller traits="resizable"
  data-trait-resizable-handle-selector=".resize-handle-right"
  data-trait-resizable-axis="horizontal"
  data-trait-resizable-min="150"
  data-trait-resizable-max="500">
  <div class="resize-panel" style="width: 300px;">
    Drag the right edge to resize horizontally.
    <div class="resize-handle resize-handle-right"></div>
  </div>
</n-controller>

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-resizable-handle-selector string '' CSS selector for the resize handle element(s) within the host.
data-trait-resizable-axis 'horizontal' | 'vertical' | 'both' 'horizontal' Constrains resize to one axis or both.
data-trait-resizable-min number — Minimum size in pixels.
data-trait-resizable-max number — Maximum size in pixels.
data-trait-resizable-disabled boolean false Disables all resize behavior when true.

Events

EventDetailDescription
native:resize-start { width, height } Fired on first pointer move after handle pointerdown.
native:resize-move { width, height } Fired on every pointer move during resize.
native:resize-end { width, height } Fired on pointer up.

Attributes (set during resize)

AttributeSet onDescription
[resizing] Host element Present while the element is being resized. Use for user-select: none.
