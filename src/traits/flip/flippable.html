API

Provider Usage

AttributeTypeDefaultDescription
data-trait-flippable-axis "x" | "y" "y" Flip axis. y = horizontal flip (rotateY), x = vertical flip (rotateX).
data-trait-flippable-duration number 600 Flip animation duration in ms.
data-trait-flippable-perspective number 1000 CSS perspective in px.
data-trait-flippable-trigger "click" | "hover" | "manual" "click" Trigger mode. hover flips on mouseenter, unflips on mouseleave. manual requires calling flip()/toggle().
data-trait-flippable-disabled boolean false Disable the flip controller.

Events

EventDetailDescription
native:flip { flipped, axis } Fired on flip/unflip. flipped is a boolean, axis is "x" or "y".

CSS

SelectorDescription
[data-flip-back] Mark the back-face element. Must have backface-visibility: hidden and the inverse rotation transform.
[flipped] Present on the host element while in the flipped state.
