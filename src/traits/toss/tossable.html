Tossable

Pick up an element, fling it with momentum — physics-based deceleration with gravity, spin, and optional viewport edge bouncing.

Provider (n-controller)

Wrap elements with <n-controller traits="tossable"> to make them tossable. Try picking up and flinging the cards.

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-tossable-friction number 0.95 Deceleration factor per frame. 0.95 = slows 5% each frame.
data-trait-tossable-bounce boolean true Bounce off viewport edges.
data-trait-tossable-bounce-damping number 0.6 Velocity multiplier on bounce (energy loss).
data-trait-tossable-gravity number 0 Gravity in px/frame2 added to vertical velocity. 0 = no gravity.
data-trait-tossable-spin boolean false Track angular velocity from pointer movement and spin during momentum.
data-trait-tossable-return-on-end boolean false Animate back to origin after momentum ends.
data-trait-tossable-disabled boolean false Disable the toss controller.

Events

EventDetailDescription
native:toss { x, y, velocityX, velocityY, bounces, rotation } Fired when momentum animation ends. bounces is the total number of edge bounces. rotation is the final angle in degrees.
native:bounce { edge, x, y } Fired on each viewport edge bounce. edge is "left", "right", "top", or "bottom".

CSS

SelectorDescription
[tossing] Present on the element while it is being dragged or animating momentum. Use for grab cursor and shadow effects.
