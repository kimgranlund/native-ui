Virtualizable

Composable trait for windowed rendering of large lists. Only renders visible items plus an overscan buffer. Dispatches native:virtual-change with the visible range so you can render only what's needed. All demos use VirtualScrollController directly since enable(scrollEl, container, totalCount) must be called to start virtualization. n-controller can create the controller declaratively, but enable() must still be called to begin.

10,000 Items

Total: 10,000 Rendered: 0 Range: 0–0 
import { VirtualScrollController } from '@nonoun/native-ui';

const host = document.getElementById('host1');
const viewport = document.getElementById('viewport1');
const content = document.getElementById('content1');

const vctrl = new VirtualScrollController(host, {
  itemHeight: 40,
  overscan: 5,
});
vctrl.enable(viewport, content, 10000);

host.addEventListener('native:virtual-change', (e) => {
  renderRows(e.detail.start, e.detail.end);
});

// Initial render
renderRows(vctrl.start, vctrl.end);

VirtualScrollController — Attach to Any Element

Use VirtualScrollController to add virtual scrolling to an existing element without subclassing. Same events, same API — no trait mixin required.

Total: 5,000 Rendered: 0 Range: 0–0 
import { VirtualScrollController } from '@nonoun/native-ui';

const host = document.getElementById('ctrl-host');
const viewport = document.getElementById('ctrl-viewport');
const content = document.getElementById('ctrl-content');

const vctrl = new VirtualScrollController(host, {
  itemHeight: 40,
  overscan: 5,
});
vctrl.enable(viewport, content, 5000);

host.addEventListener('native:virtual-change', (e) => {
  renderRows(e.detail.start, e.detail.end);
});

API

Constructor Options

OptionTypeDefaultDescription
itemHeight number 40 Fixed height (in pixels) of each virtual row. Used to calculate total scroll height and visible range.
overscan number 5 Number of extra rows to render above and below the visible viewport for smoother scrolling.

Methods

MethodReturnsDescription
enable(scrollEl, container, totalCount) void Starts virtualization. scrollEl is the scrollable viewport, container is the content wrapper, totalCount is the total number of items. Creates top/bottom spacer elements and attaches the scroll listener.
disable() void Stops virtualization and removes the scroll listener. Spacers remain in the DOM.
updateCount(count) void Updates the total item count and recalculates the visible range. Use when items are added or removed.
destroy() void Fully tears down the controller: removes scroll listener and spacer elements.

Events

EventDetailDescription
native:virtual-change { start, end, totalCount } Dispatched on the host element when the visible range changes. start is the first visible index, end is one past the last visible index. Render rows for indices [start, end).

Properties

PropertyTypeDescription
start number Current start index of the visible range (inclusive). Read-only.
end number Current end index of the visible range (exclusive). Read-only.
