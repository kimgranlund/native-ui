CSS Inspectable

Hold Option and hover to preview element outlines, click to explode layers in 3D space with interactive tilt. Click outside or press Escape to close. Like Firefox's old 3D DOM inspector.

Provider (n-controller)

Wrap elements with <n-controller traits="css-inspectable"> to make them inspectable. Hover to preview, click to explode.

Adapter Attributes (data-trait-css-inspectable-*)

Attribute Default Description
data-trait-css-inspectable-depth 60 Z-spacing between exploded layers (px)
data-trait-css-inspectable-scale 0.85 Scale factor during inspection
data-trait-css-inspectable-perspective 1200 CSS perspective distance (px)
data-trait-css-inspectable-max-tilt 25 Max mouse tilt angle (deg)
data-trait-css-inspectable-tilt-radius 300 Mouse distance for max tilt (px)
data-trait-css-inspectable-labels true Show tag/id/class labels on layers
data-trait-css-inspectable-pick false Enable pick mode (Alt+click to choose target)
data-trait-css-inspectable-disabled false Disable the inspector
