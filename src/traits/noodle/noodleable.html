Noodleable

Draw SVG noodle connections between DOM elements. Supports bezier, step, and straight curve styles. In edit mode, drag between port dots to create connections; click a noodle to remove it.

Interactive Flow Builder

Drag from a port dot to another port to create a connection. Click a noodle to delete it. Nodes are draggable via MagnetController. Hover a port and click + to add a node. Drag empty space to pan the canvas. The JSON pane on the right is live and editable.

API

Provider Usage

AttributeTypeDefaultDescription
data-trait-noodleable-selector string [data-noodle-port] CSS selector for connectable elements.
data-trait-noodleable-editable boolean false Enable drag-to-connect and click-to-delete.
data-trait-noodleable-color string var(--n-color-accent-500) Noodle stroke color.
data-trait-noodleable-stroke-width number 2 Noodle stroke width in px.
data-trait-noodleable-tension number 0.5 Bezier control point distance (0-1).
data-trait-noodleable-show-ports boolean true (when editable) Show port indicator dots.
data-trait-noodleable-port-size number 10 Port dot size in px.
data-trait-noodleable-style "bezier" | "step" | "straight" "bezier" Curve style for noodle paths.
data-trait-noodleable-animated boolean false Flowing dash animation on noodles.
data-trait-noodleable-connections JSON [] Initial connections array (JSON string of NoodleConnection[]).
data-trait-noodleable-disabled boolean false Disable the controller.

Programmatic API

MethodDescription
connect(from, to, fromPort, toPort) Create a connection between two elements by ID.
disconnect(id) Remove a connection by its ID.
getConnections() Returns the current array of connection objects.
setConnections(connections) Replace all connections with a new array.
update() Force re-render after external DOM changes (e.g. node repositioned).
clear() Remove all connections.
destroy() Teardown the controller and remove the SVG overlay.

Events

EventDetailDescription
native:noodle-connect { id, from, to, fromPort, toPort } Fired when a new connection is created.
native:noodle-disconnect { id, from, to, fromPort, toPort } Fired when a connection is removed.
native:noodle-drag { from, fromPort, x, y } Fired while a connection is being dragged from a port.

CSS

SelectorDescription
[data-noodle-port] Attribute on connectable elements. Value is a space-separated list of port sides: left, right, top, bottom.
[data-noodle-port-indicator] Port indicator dots created by the controller when showPorts is true.
[data-noodle-port-indicator][data-noodle-dragging] Source port currently being dragged from.
[data-noodle-port-indicator][data-noodle-droppable] All valid target ports during a drag (excludes the source port).
[data-noodle-port-indicator][data-noodle-drop-ready] Nearest droppable port within snap radius (30px) — shows "drop here" feedback.
