Hoverable

Pointer hover state with configurable enter/leave delays. Sets [hovered] attribute and dispatches native:hover-start / native:hover-end events.

Instant Hover

Default 0ms delays. The [hovered] attribute toggles immediately on pointer enter/leave.

Hover over me idle 
<n-controller traits="hoverable">
  <div class="hover-card">
    Hover over me
  </div>
</n-controller>

Hover Intent (500ms)

data-trait-hoverable-delay="500" prevents accidental hover triggers. Pointer must rest on the element for 500ms before activation.

Hover and wait 500ms idle 
<n-controller traits="hoverable" data-trait-hoverable-delay="500">
  <div class="hover-card">
    Hover and wait 500ms
  </div>
</n-controller>

Sticky Hover (300ms leave)

data-trait-hoverable-leave-delay="300" so the hover state persists briefly after the pointer leaves. Useful for menus or tooltips with a gap between trigger and content.

Hover, then leave slowly idle 
<n-controller traits="hoverable" data-trait-hoverable-leave-delay="300">
  <div class="hover-card">
    Hover, then leave slowly
  </div>
</n-controller>

Combined Delays

Both data-trait-hoverable-delay="400" and data-trait-hoverable-leave-delay="200". Requires intent to activate and lingers briefly on leave.

400ms enter + 200ms leave idle 
<n-controller traits="hoverable" data-trait-hoverable-delay="400" data-trait-hoverable-leave-delay="200">
  <div class="hover-card">
    400ms enter + 200ms leave
  </div>
</n-controller>

API

Properties

PropertyTypeDefaultDescription
hoverDelay number 0 Milliseconds to wait after pointer enter before setting [hovered]. Prevents accidental hover triggers.
hoverLeaveDelay number 0 Milliseconds to wait after pointer leave before removing [hovered]. Useful for menus with gaps.
hoverDisabled boolean false Disables hover behavior when true. Pointer events are ignored.

Events

EventDetailDescription
native:hover-start { pointerType } Fired when hover activates (after delay, if configured). pointerType is 'mouse', 'pen', etc.
native:hover-end { pointerType } Fired when hover deactivates (after leave delay, if configured).

CSS

SelectorDescription
[hovered] Present on the element while hover is active. Use for styling hover states with delay support.
