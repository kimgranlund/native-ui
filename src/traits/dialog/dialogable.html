Dialogable

Wraps content in a native <dialog> with modal behavior. Handles Escape key, backdrop click, and autofocus. Uses the browser's built-in top-layer and ::backdrop.

Basic Modal

Click the button to open a modal dialog. Close with Escape, the backdrop, or the Close button.

Open Dialog 
<script>
  import { DialogController } from '@nonoun/native-ui';

  const host = document.querySelector('.dialog-host');
  const ctrl = new DialogController(host);
  ctrl.showModal();
  // ctrl.close();
</script>

This is a modal dialog created by the DialogController trait. It uses the native <dialog> element for proper focus management and accessibility.

Custom Content Target

Uses the contentTarget option to wrap dialog content in a custom structure. Useful for adding scrollable bodies or custom chrome.

Open Custom Dialog 
const ctrl = new DialogController(host, {
  contentTarget: (dialog) => {
    const wrapper = document.createElement('div');
    wrapper.className = 'dialog-body';
    dialog.appendChild(wrapper);
    return wrapper; // children go here
  },
});

API

Constructor Options

OptionTypeDefaultDescription
contentTarget (dialog: HTMLDialogElement) => HTMLElement dialog itself Returns the element where host children should be moved into. The returned element must be appended to the dialog by the callback.

Host Attributes

AttributeTypeDescription
no-close-on-escape boolean Prevent closing the dialog with the Escape key.
no-close-on-backdrop boolean Prevent closing the dialog by clicking the backdrop.
open boolean (read-only) Set by the controller when the dialog is open.

Methods

MethodReturnsDescription
showModal() void Open the dialog as a modal. Idempotent when already open.
close() void Close the dialog. Dispatches a close event on the host.
destroy() void Clean up event listeners and nullify the dialog reference.

Events

EventTargetDescription
close host Dispatched when the dialog is closed (via close(), Escape, or backdrop).

Keyboard

KeyAction
Escape Close the dialog (unless no-close-on-escape is set).
