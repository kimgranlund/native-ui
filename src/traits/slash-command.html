Slash Command

Detects / prefix at the start of an input's value, shows an anchored command listbox popover, filters by query, and dispatches selection events. Works with <n-textarea> and <n-input>.

Basic Slash Commands

Type / in the textarea to see the command list. Arrow keys navigate, Enter selects, Escape closes. The input is cleared on selection. 

import { SlashCommandController } from '@nonoun/native-ui';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: [
    { value: 'help', label: 'Help', description: 'Get help' },
    { value: 'clear', label: 'Clear', description: 'Clear conversation' },
    { value: 'summarize', label: 'Summarize', description: 'Summarize the thread' },
    { value: 'translate', label: 'Translate', description: 'Translate text' },
    { value: 'format', label: 'Format', description: 'Format as markdown' },
    { value: 'search', label: 'Search', description: 'Search messages' },
  ],
});

wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command);
});

With n-input

Same pattern using <n-input> for single-line input. Type / to trigger the command popover. 

const wrapper = document.querySelector('#wrapper');
const input = wrapper.querySelector('n-input');

const slash = new SlashCommandController(wrapper, {
  input: input,
  commands: [
    { value: 'help', label: 'Help' },
    { value: 'clear', label: 'Clear' },
    { value: 'search', label: 'Search' },
  ],
});

wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command);
});

Filtered Commands

Typing after / filters the list. For example, /he shows only "Help". The filter matches against label, value, and description. The native:slash-query event fires on every keystroke with the current query and filtered command list. 

// native:slash-query fires on every keystroke after /
wrapper.addEventListener('native:slash-query', (e) => {
  const { query, commands } = e.detail;
  console.log(`Query: "${query}", matches: ${commands.length}`);
});

// native:slash-select fires when a command is chosen
wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command.label);
});

Dynamic Commands

Commands can be updated at runtime via the .commands setter. Click the button to toggle between two command sets. If the popover is open, it re-renders immediately.

Switch to Set B Current: Set A 
const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: setA,
});

// Update commands at runtime — popover re-renders if open
toggleBtn.addEventListener('native:press', () => {
  if (currentSet === 'A') {
    slash.commands = setB;
  } else {
    slash.commands = setA;
  }
});

API

Constructor Options (SlashCommandOptions)

PropertyTypeDescription
input HTMLElement The input element to monitor (n-textarea, n-input, or any element dispatching native:input).
commands SlashCommand[] Array of command definitions to display in the popover.

SlashCommand Interface

PropertyTypeRequiredDescription
value string Yes Unique identifier for the command.
label string Yes Display text shown in the popover list.
description string No Optional description (used for filtering and title attribute).
icon string No Optional icon name (reserved for future use).

Controller Properties

PropertyTypeDescription
host HTMLElement The host element the controller is attached to.
commands SlashCommand[] Get or set the command list. Setting re-renders the popover if open.
open boolean Whether the command popover is currently visible.

Controller Methods

MethodReturnsDescription
destroy() --- Hides the popover, removes all listeners, cleans up the listbox element.

Events

EventDetailDescription
native:slash-query { query, commands } Fired on host when typing after /. query is the text after the slash. commands is the filtered array.
native:slash-select { command } Fired on host when a command is selected (Enter or click). command is the full SlashCommand object.
