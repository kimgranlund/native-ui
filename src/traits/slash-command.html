Slash Command

Detects / anywhere in an input (preceded by whitespace or at text start), shows a caret-anchored command listbox popover, filters by query, and inserts a styled tag on selection. Use Cmd+/ (Ctrl+/) to toggle. Works with <n-textarea> and <n-input>.

Basic Slash Commands

Type / in the textarea to see the command list. Arrow keys navigate, Enter selects, Escape closes. A styled tag is inserted on selection. Works mid-text — try typing some text then /. 

import { SlashCommandController } from '@nonoun/native-ui';

const wrapper = document.querySelector('#wrapper');
const textarea = wrapper.querySelector('n-textarea');

const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: [
    { value: 'help', label: 'Help', description: 'Get help' },
    { value: 'clear', label: 'Clear', description: 'Clear conversation' },
    { value: 'summarize', label: 'Summarize', description: 'Summarize the thread' },
    { value: 'translate', label: 'Translate', description: 'Translate text' },
    { value: 'format', label: 'Format', description: 'Format as markdown' },
    { value: 'search', label: 'Search', description: 'Search messages' },
  ],
});

wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command);
});

With n-input

Same pattern using <n-input> for single-line input. Type / or press Cmd+/ to trigger the command popover. 

const wrapper = document.querySelector('#wrapper');
const input = wrapper.querySelector('n-input');

const slash = new SlashCommandController(wrapper, {
  input: input,
  commands: [
    { value: 'help', label: 'Help' },
    { value: 'clear', label: 'Clear' },
    { value: 'search', label: 'Search' },
  ],
});

wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command);
});

Filtered Commands

Typing after / filters the list. For example, /he shows only "Help". The filter matches against label, value, and description. The native:slash-query event fires on every keystroke with the current query and filtered command list. 

// native:slash-query fires on every keystroke after /
wrapper.addEventListener('native:slash-query', (e) => {
  const { query, commands } = e.detail;
  console.log(`Query: "${query}", matches: ${commands.length}`);
});

// native:slash-select fires when a command is chosen
wrapper.addEventListener('native:slash-select', (e) => {
  console.log('Selected:', e.detail.command.label);
});

Action Types

Commands support three action types via the action property: tag (default — inserts a styled pill), insert (inserts plain text), event (fires event only — host handles the action, e.g. opening a modal). 

const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: [
    { value: 'mention', label: '@mention', action: 'tag' },
    { value: 'heading', label: 'Heading', action: 'insert', insertText: '## ' },
    { value: 'divider', label: 'Divider', action: 'insert', insertText: '---\n' },
    { value: 'upload', label: 'Upload File', action: 'event', description: 'Open file picker' },
    { value: 'emoji', label: 'Emoji', action: 'event', description: 'Open emoji picker' },
  ],
});

Dynamic Commands

Commands can be updated at runtime via the .commands setter. Click the button to toggle between two command sets. If the popover is open, it re-renders immediately.

Switch to Set B Current: Set A 
const slash = new SlashCommandController(wrapper, {
  input: textarea,
  commands: setA,
});

// Update commands at runtime — popover re-renders if open
toggleBtn.addEventListener('native:press', () => {
  if (currentSet === 'A') {
    slash.commands = setB;
  } else {
    slash.commands = setA;
  }
});

API

Constructor Options (SlashCommandOptions)

Property Type Description input HTMLElement The input element to monitor (n-textarea, n-input, or any element dispatching native:input). commands SlashCommand[] Array of command definitions to display in the popover.

SlashCommand Interface

Property Type Required Description value string Yes Unique identifier for the command. label string Yes Display text shown in the popover list. description string No Optional description (used for filtering and title attribute). icon string No Optional icon name (reserved for future use). action 'tag' | 'insert' | 'event' No Behavior on selection. tag (default) inserts a styled pill. insert replaces /query with plain text. event removes /query and fires the event only — host handles the action. insertText string No Text to insert for action: 'insert'. Defaults to label if omitted.

Controller Properties

Property Type Description host HTMLElement The host element the controller is attached to. commands SlashCommand[] Get or set the command list. Setting re-renders the popover if open. open boolean Whether the command popover is currently visible.

Controller Methods

Method Returns Description destroy() --- Hides the popover, removes all listeners, cleans up the listbox element.

Events

Event Detail Description native:slash-query { query, commands } Fired on host when typing after /. query is the text after the slash. commands is the filtered array. native:slash-select { command, action } Fired on host when a command is selected (Enter or click). command is the full SlashCommand object. action is the resolved action type ('tag', 'insert', or 'event').

Keyboard Shortcuts

Key Action Cmd+/ / Ctrl+/ Insert / at caret and open popover (toggle) ArrowDown / ArrowUp Navigate command list Enter Select active command Tab Select closest match (when query has 2+ characters) Escape Close popover
