Gatewayable

Manages HTTP load/save state with loading, saving, error, and dirty signals. Handles fetch with abort support, custom parsers, and serializers.

Load Content

Loads content from a URL. Try loading a valid endpoint or trigger an error with a bad URL.

loading dirty error
Load /native.svg Load /not-found (404)
No content loaded
<script>
  const gw = new GatewayController(host);
  const content = await gw.load('/api/data');
  console.log(gw.loading.value); // false
  console.log(gw.error.value);   // null
</script>

Save Content

Demonstrates save with dirty tracking. Edit the textarea to mark dirty, then save to clear it. (Save uses a mock endpoint that always succeeds.)

saving dirty error
Save Mark Dirty Mark Clean 
<script>
  const gw = new GatewayController(host, {
    contentType: 'application/json',
    serialize: (c) => JSON.stringify({ content: c }),
  });
  gw.markDirty();
  const ok = await gw.save('/api/data', textarea.value);
  console.log(gw.dirty.value); // false after save
</script>

API

Constructor Options

OptionTypeDefaultDescription
parse (res: Response) => Promise<string> res.text() Custom response parser for load requests.
serialize (content: string) => BodyInit identity Custom serializer for save request bodies.
contentType string "text/plain" Content-Type header for save requests.

Signals

SignalTypeDescription
loading Signal<boolean> True while a load request is in-flight.
saving Signal<boolean> True while a save request is in-flight.
error Signal<string | null> Last error message, or null.
dirty Signal<boolean> True when content has changed since the last load or save.

Methods

MethodReturnsDescription
load(url) Promise<string | null> Fetch content from URL. Returns parsed content or null on error.
save(url, content) Promise<boolean> PUT content to URL. Returns true on success.
markDirty() void Set dirty signal to true.
markClean() void Set dirty signal to false.
abort() void Cancel any in-flight load or save requests.
destroy() void Abort and clean up.

Provider Usage

AttributeTypeDefaultDescription
data-trait-gatewayable-content-type string "text/plain" Content-Type header for save requests.
