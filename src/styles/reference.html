Customization Patterns

State-conditional intent

Override --n-* locals in a state selector to change intent on hover, focus, etc. 

/* Neutral button → accent on hover */
n-button.cta:hover {
  --n-ink:        var(--n-ink-accent);
  --n-ink-strong: var(--n-ink-strong-accent);
  --n-surface:    var(--n-surface-accent);
  --n-panel:      var(--n-panel-accent);
  --n-border:     var(--n-border-accent);
}

/* Danger intent on focus (e.g. delete confirmation) */
n-button.danger-focus:focus-visible {
  --n-ink:        var(--n-ink-danger);
  --n-surface:    var(--n-surface-danger);
}

Debug state attributes (force-*)

Every pseudo-state with a visual effect has a force-* attribute mirror for DevTools debugging and state demos. Add the attribute to the host element to simulate the pseudo-state.

Pseudo Attribute Components :hover [force-hover] All interactive components + n-card[interactive] :active [force-active] n-button, n-option, n-command-item, n-tab, n-segment :focus [force-focus] n-input, n-textarea, n-input-otp :focus-visible [force-focus-visible] All components with focus rings 
<!-- Toggle in DevTools to simulate hover -->
<n-button force-hover>Hovered</n-button>

<!-- Compound states work too -->
<n-checkbox force-hover aria-checked="true">Checked + Hovered</n-checkbox>

<!-- Internal children: force-* on host triggers all children -->
<n-calendar force-hover>...</n-calendar>

Scoped intent override

Override locals on a container to affect all children. 

/* All controls inside .danger-zone get danger colors */
.danger-zone {
  --n-ink:           var(--n-ink-danger);
  --n-ink-strong:    var(--n-ink-strong-danger);
  --n-surface:       var(--n-surface-danger);
  --n-border:        var(--n-border-danger);
  --n-border-muted:  var(--n-border-muted-danger);
}
