<n-progress>

CSS-only progress bar. Set progress via --n-progress custom property (0–1). Supports sizes, intents, and an indeterminate animation.

JavaScript-Driven

Reset Animate 
<n-progress id="bar" style="--n-progress: 0;"></n-progress>

<script>
  const bar = document.getElementById('bar');
  // Set progress from JS:
  bar.style.setProperty('--n-progress', '0.65');
</script>

API

Attributes

AttributeTypeDefaultDescription
size"xs" | "sm" | "lg"defaultTrack height. xs = 1 space, sm = 1.5 spaces, default = 2 spaces, lg = 3 spaces.
intent"accent" | "success" | "warning" | "danger"neutralFill bar color intent. Uses --n-ink resolved by intent.
indeterminatebooleanfalseShows a looping animation instead of a fixed fill width.
radius"sharp" | "round" | "pill"inheritedBorder radius preset. Inherits --n-radius.

CSS Custom Properties

PropertyDefaultDescription
--n-progress0Progress value from 0 to 1. Controls the fill bar width.
--n-radiusinheritedBorder radius of both track and fill.
--n-controlinheritedTrack background color.
--n-inkinheritedFill bar color (resolved by intent).
--n-spaceinheritedBase spacing unit used for track height calculations.
--n-durationinheritedTransition duration for fill width changes.
--n-easinginheritedTransition easing curve for fill width changes.
