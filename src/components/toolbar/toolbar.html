<n-toolbar>

Horizontal action bar for grouping related controls. Minimal custom element with role="toolbar" and roving keyboard focus.

Vertical Orientation

orientation="vertical" stacks items vertically and switches keyboard navigation from ArrowLeft/ArrowRight to ArrowUp/ArrowDown.

</n-toolbar>

Plain Variant

variant="plain" strips background, border, and radius so the toolbar can embed inside containers like <n-container> headers without doubling chrome. 

<!-- Default: panel background + border + radius -->
<n-toolbar>...</n-toolbar>

<!-- Plain: transparent, no border, no radius -->
<n-toolbar variant="plain">...</n-toolbar>

Fill Mode

[fill] distributes available space evenly across items. Default is compact (intrinsic width).

<!-- Default: intrinsic width -->
<n-toolbar>...</n-toolbar>

<!-- Fill: items grow to distribute space -->

Grouped Overflow

<n-toolbar-group> keeps related actions together — the entire group overflows as one unit instead of splitting.

</n-toolbar>

Overflow Priority

overflow-priority="high|normal|low" controls which items hide first when space is limited. overflow-pin keeps an item always visible.

Save Export Print Share Settings 
<n-toolbar>
  <n-button overflow-priority="high">Save</n-button>   <!-- hides last -->
  <n-button>Export</n-button>                          <!-- normal (default) -->
  <n-button overflow-priority="low">Print</n-button>   <!-- hides first -->
  <n-button overflow-pin>Settings</n-button>           <!-- always visible -->
</n-toolbar>

Overflow Diagnostics

native:toolbar-overflow fires whenever visibility changes. Resize the container to see the event payload.

Save Export 
toolbar.addEventListener('native:toolbar-overflow', (e) => {
  const { visibleCount, overflowedCount, overflowedLabels } = e.detail;
  console.log(`${visibleCount} visible, ${overflowedCount} overflowed`);
  console.log('Hidden:', overflowedLabels);
});
