<ui-tabs>

Tab navigation with roving focus, panel switching, and a sliding underline indicator. Supports horizontal and vertical orientations.

Horizontal (default)

Overview Features Pricing

This is the overview panel. Use arrow keys to navigate between tabs.

Features include roving focus, ARIA tab/tabpanel semantics, and a smooth sliding indicator.

Check out our competitive pricing plans for teams of all sizes.

 
<ui-tabs value="overview">
  <ui-tab value="overview">Overview</ui-tab>
  <ui-tab value="features">Features</ui-tab>
  <ui-tab value="pricing">Pricing</ui-tab>
  <ui-tab-panels>
    <ui-tab-panel value="overview"><p>Overview content.</p></ui-tab-panel>
    <ui-tab-panel value="features"><p>Features content.</p></ui-tab-panel>
    <ui-tab-panel value="pricing"><p>Pricing content.</p></ui-tab-panel>
  </ui-tab-panels>
</ui-tabs>
