API

Attributes

AttributeTypeDefaultDescription
intent"accent" | "info" | "success" | "warning" | "danger"neutralSemantic color intent.
size"xs" | "sm" | "md" | "lg" | "xl""md"Badge size scale.
variant"default" | "outline" | "ghost"solid (no attribute)Visual variant. Omit for solid fill.
radius"sharp" | "round"pill (9999px)Border radius preset.
floatingbooleanfalseAbsolutely positions the badge (top-right) for overlaying on icons or avatars. Parent needs position: relative.
dotbooleanfalseRenders as a small status dot with no text content.
hiddenbooleanfalseHides the badge (display: none).
maxnumbernoneClamps displayed numeric value. Shows max+ when exceeded (e.g. 99+).
