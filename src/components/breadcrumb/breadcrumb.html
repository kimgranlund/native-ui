Debug States (force-*)

Attribute-driven pseudo-state overrides for DevTools debugging and visual testing.

Force hover Force focus-visible Current

API

Attributes (n-breadcrumb)

AttributeTypeDefaultDescription
aria-labelstring"Breadcrumb"Accessible label for the navigation landmark.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Attributes (n-breadcrumb-item)

AttributeTypeDefaultDescription
hrefstring—Navigation URL. Navigates on click or Enter/Space.
currentbooleanfalseMarks as the current page. Disables navigation and sets aria-current="page".

CSS Selectors

SelectorDescription
[current]Current page item. Bold text, non-interactive.
[force-hover]Forces hover appearance on items for debugging/testing.
[force-focus-visible]Forces focus ring on items for debugging/testing.

Keyboard

KeyAction
Enter / SpaceNavigate to the item's href.
TabMove focus between breadcrumb items.

Accessibility

PropertyValue
Role (n-breadcrumb)navigation (via ElementInternals)
Role (n-breadcrumb-item)link (via ElementInternals)
Current pagearia-current="page" and aria-disabled="true" on [current] items.
SeparatorCSS ::after pseudo-element (/ by default, configurable via --n-breadcrumb-separator).
