<n-tabs>

Tab navigation with roving focus, panel switching, and a sliding underline indicator. Supports horizontal and vertical orientations.

Horizontal (default)

Overview Features Pricing

This is the overview panel. Use arrow keys to navigate between tabs.

Features include roving focus, ARIA tab/tabpanel semantics, and a smooth sliding indicator.

Check out our competitive pricing plans for teams of all sizes.

  <n-tab value="overview">Overview</n-tab>

API


    

      
Attributes — <n-tabs>

      

        
AttributeTypeDefaultDescription

        
          
valuestring—Currently selected tab value.

          
disabledbooleanfalseDisables all tabs. Cascades to child <n-tab> elements.

          
orientation"horizontal" | "vertical""horizontal"Layout direction. Horizontal uses row layout with underline indicator; vertical uses column with side indicator.

          
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.

          
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

          
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.

          
inlinebooleanfalseShrink-wraps the tabs container.

        
      

    


    

      
Attributes — <n-tab>

      

        
AttributeTypeDefaultDescription

        
          
valuestring—Tab value used for selection matching.

          
disabledbooleanfalseDisables this individual tab.

        
      

    


    

      
Events

      

        
EventDetailDescription

        
          
native:change{ value, label }Fired when the active tab changes.

        
      

    


    

      
CSS Selectors

      

        
SelectorTargetDescription

        
          
[aria-selected="true"]n-tabActive tab.

          
[aria-disabled="true"]n-tabsDisabled tablist.

          
[pressed]n-tabPresent while pointer or key is held down.

          
[force-hover]n-tabForces hover appearance on tab.

          
[force-active]n-tabForces active appearance on tab.

          
[force-focus-visible]n-tabForces focus ring on tab.

        
      

    


    

      
Keyboard

      

        
KeyAction

        
          
ArrowRight / ArrowDownMoves to next tab and selects it.

          
ArrowLeft / ArrowUpMoves to previous tab and selects it.

          
HomeMoves to first tab.

          
EndMoves to last tab.
