Close Prevention

No Close on Escape No Close on Backdrop Persistent (both)
No Escape Close

Pressing Escape won't close this drawer. Use the close button.

 No Backdrop Close

Clicking the backdrop won't close this drawer. Use the close button or Escape.

 Persistent Drawer

Neither Escape nor backdrop click will close this. Only the close button works.

API

Attributes

AttributeTypeDefaultDescription
side"left" | "right" | "top" | "bottom""right"Slide-in direction.
no-close-on-escapebooleanfalsePrevents closing on Escape key.
no-close-on-backdropbooleanfalsePrevents closing on backdrop click.

Methods

MethodDescription
showModal()Opens the drawer as a modal dialog.
close()Closes the drawer.

Properties

PropertyTypeDescription
openboolean (read-only)Whether the drawer is currently open.

Events

EventDetailDescription
close—Fired when the drawer is closed.

CSS Custom Properties

PropertyDefaultDescription
--n-drawer-width—Width of the drawer panel (left/right sides). Capped at 90vw.
--n-drawer-height—Height of the drawer panel (top/bottom sides). Capped at 90vh.

Keyboard

KeyAction
EscapeCloses the drawer (unless no-close-on-escape).

Accessibility

PropertyValue
StructureUses native <dialog> with showModal() for top-layer rendering and focus trapping.
BackdropClick-to-close (unless no-close-on-backdrop).
AnimationSlide-in from the specified side. Respects prefers-reduced-motion.
