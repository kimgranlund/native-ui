<n-avatar>

User/entity image with initials fallback. Shows image, initials from name, or placeholder.

Initials

KG JD A BS 
<n-avatar name="Kim Granlund"></n-avatar>
<n-avatar name="Jane Doe"></n-avatar>
<n-avatar name="Alice"></n-avatar>

Fallback

<!-- No name or src: shows generic placeholder -->
<n-avatar></n-avatar>

Image (broken src falls back)

<!-- Broken src falls back to initials from name -->
<n-avatar src="/photo.jpg" name="Fallback User"></n-avatar>

API

Attributes

AttributeTypeDefaultDescription
namestringnoneUser/entity name. Used for accessible label and initials fallback.
srcstringnoneImage URL. Falls back to initials (from name) or placeholder icon on error.
size"xs" | "sm" | "md" | "lg" | "xl""md"Avatar size scale.
intent"accent" | "info" | "success" | "warning" | "danger"neutralSemantic color intent for the background fill.
radius"sharp" | "round" | "circle""circle"Border radius preset.

CSS Custom Properties

PropertyDefaultDescription
--n-radiusinheritedBorder radius. Override for custom rounding.
