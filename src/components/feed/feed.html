API Reference

Attributes

AttributeTypeDefaultDescription
align'start' | 'end'startContent alignment. end pushes content to bottom (chat-style).
scrollboolean—Enable scroll container (overflow-y: auto). CSS-only.
auto-scrollboolean—Auto-scroll to bottom when new content is added (while pinned).
virtualboolean—Enable virtual scroll windowing for large lists.
virtual-item-heightnumber80Estimated item height in px for virtual scroll calculations.
virtual-overscannumber5Extra items to render outside the visible viewport.

Properties

PropertyTypeDescription
isPinnedbooleanWhether the feed is scrolled to the bottom (read-only).
itemsunknown[]Data items for virtual rendering.
itemRenderer(item, index) => HTMLElementCallback that creates an element from a data item.

Methods

MethodDescription
scrollToBottom(smooth?)Scroll to the bottom of the feed. Pass false for instant scroll.

Events

EventDetailDescription
native:feed-scroll{ isPinned, scrollTop }Fired when pin state changes (scrolled to/from bottom).
native:range-change{ start, end, total }Fired when virtual scroll visible range changes.

CSS Tokens

TokenDefaultDescription
--n-feed-gapcalc(var(--n-space) * 2)Gap between feed items.
