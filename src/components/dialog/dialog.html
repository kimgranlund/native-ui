<n-dialog>

Modal dialog built on native <dialog>. Opens via showModal(), closes on backdrop click, Escape, or programmatically. Content is promoted to the top layer with full token re-establishment.

Basic Dialog

Open Dialog Confirm Action

Are you sure you want to continue? This action cannot be undone.

 Cancel Confirm 
<n-button id="open-btn">Open Dialog</n-button>

<n-dialog id="my-dialog">
  <n-container>
    <n-header><span>Confirm Action</span></n-header>
    <n-body>
      <p>Are you sure you want to continue?</p>
    </n-body>
    <n-footer>
      <n-button id="cancel-btn">Cancel</n-button>
      <n-button id="confirm-btn" intent="accent">Confirm</n-button>
    </n-footer>
  </n-container>
</n-dialog>

<script>
  const dialog = document.getElementById('my-dialog');
  document.getElementById('open-btn')
    .addEventListener('native:press', () => dialog.showModal());
  document.getElementById('cancel-btn')
    .addEventListener('native:press', () => dialog.close());
  document.getElementById('confirm-btn')
    .addEventListener('native:press', () => dialog.close());
</script>

API

Attributes

AttributeTypeDefaultDescription
no-close-on-escapebooleanfalsePrevents closing the dialog on Escape key press.
no-close-on-backdropbooleanfalsePrevents closing the dialog on backdrop click.

Methods

MethodDescription
showModal()Opens the dialog as a modal (top layer). Creates a native <dialog> and calls dialog.showModal().
close()Closes the dialog.

Events

EventDetailDescription
close—Fired when the dialog is closed.

CSS Custom Properties

PropertyDefaultDescription
--n-dialog-widthautoWidth of the dialog content.
--n-dialog-shadownoneBox shadow on the dialog content.
--n-backdrop-colorthemeBackdrop color behind the dialog.
--n-backdrop-opacitythemeBackdrop opacity.

Keyboard

KeyAction
EscapeCloses the dialog (unless no-close-on-escape is set).
TabCycles focus within the dialog (focus trap).

Accessibility

PropertyValue
PatternCreates a native <dialog> element, promoted to the top layer via showModal(). CSS custom properties inherit normally.
Focus trapYes — Tab cycles within the dialog while open.
BackdropNative ::backdrop pseudo-element styled with --n-backdrop-* tokens.
