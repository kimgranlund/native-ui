<n-accordion>

Collapsible disclosure sections with native <details> under the hood. Supports single and multiple open modes.

Single Mode (default)

What is this library? A pure CSS + Web Component design system built on OKLCH color science, CSS custom property inheritance, and zero-specificity attribute selectors. How does the cascade work? Every value a component consumes flows through three tiers: Public (--n-*) tokens, Local (--n-*) resolved by attribute selectors, and Component reads. Can I customize colors? Yes! Override the 9 color environment parameters in n-primitives.css or use the theme presets (forest, rose, zinc) for quick changes. 
<n-accordion>
  <n-accordion-item open>
    <span slot="heading">Section title</span>
    Section content goes here.
  </n-accordion-item>
  <n-accordion-item>
    <span slot="heading">Another section</span>
    More content here.
  </n-accordion-item>
</n-accordion>

Multiple Mode

Section One This section can stay open while others open too. In multiple mode, opening one doesn't close the others. Section Two Both this and Section One can be open simultaneously. Try opening and closing independently. Section Three Click to open this section without affecting the others above.

API

Attributes (n-accordion)

AttributeTypeDefaultDescription
multiplebooleanfalseAllows multiple items to be open simultaneously. When removed, closes all but the first open item.
disabledbooleanfalseDisables all accordion items. Sets aria-disabled="true".
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Attributes (n-accordion-item)

AttributeTypeDefaultDescription
openbooleanfalseWhether the item content is expanded.
disabledbooleanfalseDisables toggling this item.

Slots (n-accordion-item)

SlotDescription
headingSummary text shown in the clickable header row.
(default)Collapsible content panel.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state on accordion or item.
[open]Present on expanded accordion items.
[force-hover]Forces hover on item summary for debugging/testing.
[force-focus-visible]Forces focus ring on item summary for debugging/testing.

Keyboard

KeyAction
Enter / SpaceToggle the focused item open/closed.
TabMove focus between summary elements.

Accessibility

PropertyValue
StructureUses native <details>/<summary> for built-in disclosure semantics.
FocusSummary elements are natively focusable.
