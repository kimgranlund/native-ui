API

Attributes (n-sidebar-nav)

AttributeTypeDefaultDescription
valuestring—Currently selected nav item value.
disabledbooleanfalseDisables all nav items. Sets aria-disabled="true".
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Attributes (n-sidebar-nav-item)

AttributeTypeDefaultDescription
valuestring""Item value emitted on selection.
disabledbooleanfalseDisables this individual nav item.

Events

EventDetailDescription
native:change{ value, label }Fired when selection changes.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state on nav or individual item.
n-sidebar-nav-item[aria-current="page"]Currently selected nav item.
n-sidebar-nav-item[force-hover]Forces hover appearance on a nav item.
n-sidebar-nav-item[force-active]Forces active appearance on a nav item.
n-sidebar-nav-item[force-focus-visible]Forces focus ring on a nav item.

Keyboard

KeyAction
ArrowUp / ArrowDownMove focus between nav items (roving focus).
HomeFocus first nav item.
EndFocus last nav item.
Enter / SpaceSelect the focused nav item.

Accessibility

PropertyValue
Rolenavigation (via ElementInternals)
Selectionaria-current="page" on the selected item.
FocusRoving focus via ListNavigateController (vertical orientation).
