Keyboard Navigation

Key Action
Arrow DownMove to next item
Arrow UpMove to previous item
HomeJump to first item
EndJump to last item
EnterSelect active item
EscapeDismiss (fires native:dismiss event)
TypeFilter items by search text

API

Attributes

AttributeTypeDefaultDescription
disabledbooleanfalseDisables all interaction. Sets aria-disabled="true".
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Child Elements

ElementDescription
<n-command-input>Search input wrapper. Contains a native <input> for typing.
<n-command-list>Scrollable container for items and groups.
<n-command-group>Group of related items with a heading. Auto-hides when all items are filtered out.
<n-command-item>Selectable action item. Uses same CSS as n-option.
<n-command-empty>Empty state shown when no items match the filter.

Events

EventDetailDescription
native:change{ value, label }Fired when an item is selected (click or Enter).
native:dismiss—Fired on Escape key press.

CSS Selectors

SelectorTargetDescription
[aria-disabled="true"]n-commandDisabled state on the command palette.
[active]n-command-itemKeyboard-highlighted item.
[hidden]n-command-itemFiltered-out item.
[force-hover]n-command-itemForces hover appearance on item.
[force-active]n-command-itemForces active appearance on item.

Keyboard

KeyAction
ArrowDownMoves to next visible item.
ArrowUpMoves to previous visible item.
HomeMoves to first visible item.
EndMoves to last visible item.
EnterSelects the active item.
EscapeFires native:dismiss event.
