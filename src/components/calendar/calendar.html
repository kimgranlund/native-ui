<n-calendar>

Date selection with day, month, and year views. Supports single selection, date range, min/max constraints, and keyboard navigation.

Single Select

Select a date 
<n-calendar></n-calendar>

Initial Value

<n-calendar value="2026-02-14"></n-calendar>

Min/Max Constraints

Only dates between Feb 10–25 are selectable. 

<n-calendar min="2026-02-10" max="2026-02-25"></n-calendar>

Range Selection

Click a start date, hover to preview range, click to commit. Click again to clear. 
<n-calendar range></n-calendar>

API

Attributes

AttributeTypeDefaultDescription
valuestring—Selected date in ISO format (YYYY-MM-DD).
minstring—Minimum selectable date in ISO format. Dates before this are disabled.
maxstring—Maximum selectable date in ISO format. Dates after this are disabled.
rangebooleanfalseEnables range selection mode (click start, hover preview, click end, click clear).
disabledbooleanfalseDisables all interaction. Sets aria-disabled="true".
namestring—Form field name for form association.
requiredbooleanfalseMarks the field as required for form validation.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.

Events

EventDetailDescription
native:change{ value }Fired on single date selection. value is ISO format (YYYY-MM-DD).
native:range-select{ start, end }Fired on range commit (range mode only). Both values in ISO format.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state. Dims all content and prevents interaction.
[force-hover]Forces hover appearance on all internal cells.
[force-focus-visible]Forces focus ring on the calendar container.
[view="day"]Day view (7-column grid).
[view="month"]Month view (4-column grid).
[view="year"]Year view (4-column grid).
