StoreController

Reactive signal-based store exposed via the context protocol. <n-controller provides="..."> creates a StoreController instance that descendants can consume.

1. Static Store (data-store-* attributes)

The provider seeds signals from data-store-* attributes. Consumer elements read them reactively.

Change name to Bob Change role to Editor

2. Fetch Store (src attribute)

The provider fetches JSON from a URL. Each top-level key becomes a signal. This demo uses a data: URL to simulate a fetch.

Load profile data

3. Nested Providers

Inner providers shadow outer ones with the same key. Each consumer resolves to the closest ancestor provider.

4. Loading & Error States

StoreController exposes loading and error signals for async fetch state.
