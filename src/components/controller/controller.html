n-controller

Two patterns for applying traits declaratively. Injection adds traits="..." directly on a component. Provider uses <n-controller> to apply traits to children, with options on the controller element.

Injection — Simple Injection

Hoverable

traits="hoverable" on a NativeElement subclass. Options come from the element's own attributes.

Instant hover 400ms delay 300ms sticky 
<inject-demo traits="hoverable">
  Instant hover
</inject-demo>

<inject-demo traits="hoverable" data-trait-hoverable-delay="400">
  400ms delay
</inject-demo>

<inject-demo traits="hoverable" data-trait-hoverable-leave-delay="300">
  300ms sticky
</inject-demo>

Pressable & Multi-Trait

Space-separated names: traits="hoverable pressable". Both controllers on one element.

Pressable only Hoverable + Pressable 
<inject-demo traits="pressable">
  Pressable only
</inject-demo>

<inject-demo traits="hoverable pressable">
  Hoverable + Pressable
</inject-demo>

getTraitController() — Runtime Access

Call el.getTraitController('hoverable') to modify the controller at runtime.

Hover me (delay changes at runtime) Set delay 1000ms Reset 
const hover = el.getTraitController('hoverable');
hover.delay = 1000; // now requires 1s hover intent

Provider — Simple Provider

Wrapper Mode (default)

No for — traits apply to first element child. Options live on the <n-controller>.

Wrapped child gets hoverable (200ms delay) 
<n-controller traits="hoverable" data-trait-hoverable-delay="200">
  <div class="demo-card">
    Wrapped child gets hoverable (200ms delay)
  </div>
</n-controller>

Selector Mode — Hoverable

for=".card" applies hoverable to all matching descendants. One controller, many targets.

Card A
Card B
Card C
 
<n-controller traits="hoverable" data-trait-hoverable-delay="100" for=".card">
  <div class="flex-row">
    <div class="card">Card A</div>
    <div class="card">Card B</div>
    <div class="card">Card C</div>
  </div>
</n-controller>

Dynamic Children (auto-wiring)

MutationObserver auto-wires traits when new children matching the selector are added.

Add Item Clear 
<n-controller traits="hoverable pressable" for=".dynamic-item">
  <div id="dynamic-list"></div>
</n-controller>

// New items automatically get hoverable + pressable
const item = document.createElement('div');
item.className = 'dynamic-item';
list.appendChild(item);

Live Option Updates

Changing data-trait-hoverable-delay on the controller updates all managed targets via update().

Target B

Draggable — Swap (drop)

data-trait-draggable-mode="drop" highlights the target. Consumer decides the swap logic on native:drop.

⠇Design
⠇Develop
⠇Deploy
 
<n-controller
  traits="draggable"
  for="#list"
  data-trait-draggable-selector=".drag-item"
  data-trait-draggable-mode="drop"
>
  ...
</n-controller>

list.addEventListener('native:drop', (e) => {
  const { item, target } = e.detail;
  // Swap DOM positions
  const ph = document.createElement('div');
  item.before(ph);
  target.before(item);
  ph.replaceWith(target);
});

Pattern Comparison

AspectInjectionProvider
Syntax <el traits="hoverable"> <n-controller traits="hoverable" for=".x">
Options source On the element itself On the <n-controller>
Targets The element itself Matched descendants (or first child)
Dynamic Watches traits attribute changes Watches child additions/removals
Requires NativeElement Yes (connectedCallback reads traits) No — targets can be plain HTMLElement
Access controller el.getTraitController('name') Via adapter internals
Best for Self-contained components Applying traits to plain HTML / third-party elements
