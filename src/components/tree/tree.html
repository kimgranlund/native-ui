Debug States (force-*)

Attribute-driven pseudo-state overrides for DevTools debugging and visual testing. Applied to individual n-tree-item elements.

Force hover Force focus-visible Normal

API

Attributes (n-tree)

AttributeTypeDefaultDescription
disabledbooleanfalseDisables interaction for all tree items. Sets aria-disabled="true".
aria-labelstring"Tree"Accessible label for the tree landmark.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Attributes (n-tree-item)

AttributeTypeDefaultDescription
expandedbooleanfalseWhether child items are visible.
selectedbooleanfalseWhether this item is selected.
disabledbooleanfalseDisables interaction for this item.

Slots (n-tree-item)

SlotDescription
labelThe clickable label row. Made focusable for roving focus.
(default)Child n-tree-item elements (nested items).

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state on tree or item.
[expanded]Present on expanded tree items. Shows child group.
[aria-selected="true"]Selected item. Highlighted background.
[expandable]Auto-set on items with child tree items. Adds caret icon.
[force-hover]Forces hover on item label for debugging/testing.
[force-focus-visible]Forces focus ring on item label for debugging/testing.

Keyboard

KeyAction
ArrowUp / ArrowDownMove focus between visible item labels (roving focus).
ArrowRightExpand the focused item, or move focus to first child.
ArrowLeftCollapse the focused item, or move focus to parent item.
Enter / SpaceSelect the focused item and toggle expand/collapse.
Home / EndMove focus to first/last visible item (roving focus).

Accessibility

PropertyValue
Role (n-tree)tree (via ElementInternals)
Role (n-tree-item)treeitem (via ElementInternals)
ARIA attributesaria-expanded on expandable items, aria-selected on all items.
FocusRoving focus on [slot="label"] elements. Single tabindex="0" in the tree.
