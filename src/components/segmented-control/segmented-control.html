API

Attributes

AttributeTypeDefaultDescription
valuestring—Currently selected segment value.
disabledbooleanfalseDisables all segments. Sets aria-disabled="true".
namestring—Form field name for form association.
requiredbooleanfalseMarks the field as required for form validation.
inlinebooleanfalseShrink-wraps the control instead of filling available width.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Attributes (n-segment)

AttributeTypeDefaultDescription
valuestring""Segment value emitted on selection.
disabledbooleanfalseDisables this individual segment.

Events

EventDetailDescription
native:change{ value, label }Fired when selection changes.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state on control or individual segment.
n-segment[aria-checked="true"]Currently selected segment.
n-segment[pressed]Present while pointer or key is held down on a segment.
n-segment[force-hover]Forces hover appearance on a segment.
n-segment[force-active]Forces active appearance on a segment.
n-segment[force-focus-visible]Forces focus ring on a segment.

Keyboard

KeyAction
ArrowLeft / ArrowRightMove focus between segments (roving focus).
HomeFocus first segment.
EndFocus last segment.
Enter / SpaceSelect the focused segment.
