API

Attributes

AttributeTypeDefaultDescription
checkedbooleanfalseWhether the checkbox is checked.
indeterminatebooleanfalseIndeterminate (mixed) state. Clears on first press, then toggles normally.
disabledbooleanfalseDisables interaction. Sets aria-disabled="true" and removes from tab order.
requiredbooleanfalseMarks as required for form validation.
namestring—Form field name.
valuestring"on"Form value submitted when checked.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Events

EventDetailDescription
native:change{ checked, value }Fired on toggle.

CSS Selectors

SelectorDescription
[aria-checked="true"]Checked state.
[aria-checked="mixed"]Indeterminate state.
[aria-checked="false"]Unchecked state.
[aria-disabled="true"]Disabled state.
[pressed]Present while pointer or key is held down.
[force-hover]Forces hover appearance for debugging/testing.
[force-active]Forces active appearance for debugging/testing.
[force-focus-visible]Forces focus ring for debugging/testing.

Keyboard

KeyAction
EnterToggles the checkbox.
SpaceToggles the checkbox (on key up).

PropertyValue
