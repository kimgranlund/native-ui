API

Attributes

AttributeTypeDefaultDescription
valuenumber50Current value.
minnumber0Minimum value.
maxnumber100Maximum value.
stepnumber1Step increment. Values snap to this increment.
disabledbooleanfalseDisables interaction. Sets aria-disabled="true" and removes from tab order.
requiredbooleanfalseMarks as required for form validation.
namestring—Form field name for submission.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Events

EventDetailDescription
native:input{ value }Fired continuously during drag.
native:change{ value }Fired on drag end or keyboard change.

CSS Selectors

SelectorDescription
[pressed]Present while the thumb is being dragged.
[aria-disabled="true"]Disabled state. Use for custom disabled styling.
[force-hover]Forces hover appearance for debugging/testing.
[force-active]Forces active/pressed appearance for debugging/testing.
[force-focus-visible]Forces focus ring on thumb for debugging/testing.

Keyboard

KeyAction
ArrowRight / ArrowUpIncrease by step.
ArrowLeft / ArrowDownDecrease by step.
PageUpIncrease by step × 10.
PageDownDecrease by step × 10.
HomeJump to minimum.
EndJump to maximum.
