<n-select>

Coordinator element that wires a button trigger + popover listbox into a dropdown select.

Basic Usage

Choose a fruit Apple Banana Cherry Grape Orange 
<n-select>
  <n-button justify="spread">
    <span slot="label">Choose a fruit</span>
    <n-icon name="caret-up-down" slot="trailing"></n-icon>
  </n-button>
  <n-listbox popover>
    <n-option value="apple">Apple</n-option>
    <n-option value="banana">Banana</n-option>
    <n-option value="cherry">Cherry</n-option>
  </n-listbox>
</n-select>

Pre-selected Value

Data-Driven: Dynamic Update

  const sel = document.getElementById('my-select');
  sel.options = [
    { value: 'apple', label: 'Apple' },
    { value: 'banana', label: 'Banana' },
  ];
</script>
