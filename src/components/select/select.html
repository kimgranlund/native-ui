<n-select>

Coordinator element that wires a button trigger + popover listbox into a dropdown select.

Basic Usage

Choose a fruit Apple Banana Cherry Grape Orange 
<n-select>
  <n-button justify="spread">
    <span slot="label">Choose a fruit</span>
    <n-icon name="caret-up-down" slot="trailing"></n-icon>
  </n-button>
  <n-listbox popover>
    <n-option value="apple">Apple</n-option>
    <n-option value="banana">Banana</n-option>
    <n-option value="cherry">Cherry</n-option>
  </n-listbox>
</n-select>

Data-Driven: Inline JSON

<n-select
  placeholder="Choose a country"
  options='[{"value":"us","label":"United States"},{"value":"gb","label":"United Kingdom"}]'
></n-select>

Data-Driven: Pre-selected Value

<n-select
  placeholder="Choose a country"
  value="de"
  options='[{"value":"us","label":"United States"},{"value":"de","label":"Germany"}]'
></n-select>

Data-Driven: Disabled Options

<n-select
  placeholder="Choose a role"
  options='[{"value":"viewer","label":"Viewer"},{"value":"admin","label":"Admin","disabled":true}]'
></n-select>

Data-Driven: Dynamic Update

Load fruits Load colors 
<n-select id="my-select" placeholder="Choose a fruit" options="[]"></n-select>

<script>
  const sel = document.getElementById('my-select');
  sel.options = [
    { value: 'apple', label: 'Apple' },
    { value: 'banana', label: 'Banana' },
  ];
</script>

API

Attributes

AttributeTypeDefaultDescription
valuestring—Currently selected value. Reflects to attribute.
disabledbooleanfalseDisables interaction. Cascades to trigger button and closes popover.
requiredbooleanfalseMarks as required for form validation.
namestring—Form field name.
optionsstring (JSON)—JSON array of { value, label } objects. Activates data-driven mode.
srcstring (URL)—URL to fetch options from. Activates data-driven mode.
placeholderstring—Placeholder text when no value is selected (data-driven mode only).
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only, cascades from parent.

Events

EventDetailDescription
native:change{ value, label, previousValue }Fired when selection changes.

Keyboard

KeyAction
Enter / SpaceToggles popover when closed. Selects active option when open.
ArrowDownOpens popover and moves to next option.
ArrowUpOpens popover and moves to previous option.
EscapeCloses the popover.
HomeMoves to first option.
EndMoves to last option.

Accessibility

PropertyValue
PatternCoordinator — display: contents, no visual presence. Wires ARIA + events between trigger button and popover listbox.
Trigger ARIAaria-haspopup="listbox", aria-controls, aria-expanded
Form associatedYes — participates in form submission, validation, reset, and restore.
FocusFocus lives on the trigger <n-button> child.
