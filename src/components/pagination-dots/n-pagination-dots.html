Programmatic control

    
      
      

        Previous
        Next
        Reset
      

    
const dots = document.querySelector('n-pagination-dots');
dots.active = 3;   // jump to index 3
dots.count = 8;    // change total count
dots.prev();       // go to previous
dots.next();       // go to next

API


    

      
Attributes

      

        
AttributeTypeDefaultDescription

        
          
countnumber0Number of dots to render.

          
activenumber0Zero-based index of the active dot.

          
max-dotsnumber7Maximum visible dots before windowing. Edge dots scale down when more exist beyond view.

          
paddlesbooleanfalseShows prev/next navigation buttons.

          
orientation"horizontal" | "vertical""horizontal"Layout direction of the dots.

          
variant"plain"—Removes container background and padding.

          
disabledbooleanfalseDisables all dots. Sets aria-disabled="true".

          
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

          
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.

          
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

        
      

    


    

      
Events

      

        
EventDetailDescription

        
          
native:change{ index }Fired when a dot is clicked or navigated to. index is the zero-based dot index.

        
      

    


    

      
CSS Selectors

      

        
SelectorDescription

        
          
[aria-disabled="true"]Disabled state. Dims all dots and prevents interaction.

          
[force-hover]Forces hover appearance on inactive dots.

          
[force-active]Forces active/pressed appearance on inactive dots.

          
[force-focus-visible]Forces focus ring on dot buttons.

        
      

    


    

      
Keyboard

      

        
KeyAction

        
          
ArrowRight / ArrowDownMove to next dot (wraps around, direction-dependent).

          
ArrowLeft / ArrowUpMove to previous dot (wraps around, direction-dependent).

          
HomeGo to first dot.

          
EndGo to last dot.

        
      

    


    

      
Accessibility

      

        
PropertyValue

        
          
Roletablist (via ElementInternals)

          
Labelaria-label="Slide indicators" (default, overridable)

          
DotsEach dot is role="tab" with aria-selected and aria-label="Go to slide N".

          
FocusRoving tabindex — only the active dot is focusable.
