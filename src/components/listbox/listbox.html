API

Attributes

AttributeTypeDefaultDescription
disabledbooleanfalseDisables interaction. Sets aria-disabled="true".
multiplebooleanfalseEnables multi-select mode (toggle selection).
virtual-focusbooleanfalseUses [active] attribute instead of roving tabindex. Set automatically by <n-combobox>.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Events

EventDetailDescription
native:change{ value, label }Fired when selection changes (click or keyboard).

CSS Selectors

SelectorTargetDescription
[aria-disabled="true"]n-listboxDisabled state on the listbox.
[aria-selected="true"]n-optionSelected option.
[active]n-optionKeyboard-highlighted option.
[force-hover]n-optionForces hover appearance on option.
[force-active]n-optionForces active appearance on option.
[force-focus-visible]n-optionForces focus ring on option.

Keyboard

KeyAction
ArrowDownMoves to next option.
ArrowUpMoves to previous option.
HomeMoves to first option.
EndMoves to last option.
Enter / SpaceSelects the focused option.

PropertyValue
