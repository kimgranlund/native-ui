<n-pagination>

Page navigation. Stamps prev/next + page numbers with ellipsis truncation.

Basic

<n-pagination total="10" value="1"></n-pagination>

Middle Page

<n-pagination total="20" value="10"></n-pagination>

Few Pages

<n-pagination total="3" value="2"></n-pagination>

Many Pages

<n-pagination total="100" value="50" siblings="2"></n-pagination>

Boundaries

boundaries="2" (show 2 pages at each edge)

boundaries="0" (no boundary pages)

 
<n-pagination total="50" value="25" boundaries="2"></n-pagination>
<n-pagination total="50" value="25" boundaries="0"></n-pagination>

Sizes

<n-pagination total="10" value="3" size="sm"></n-pagination>
<n-pagination total="10" value="3"></n-pagination>
<n-pagination total="10" value="3" size="lg"></n-pagination>

Live (click to navigate)

Current page: 5 

<n-pagination total="15" value="5"></n-pagination>

<script>
  const pag = document.querySelector('n-pagination');
  pag.addEventListener('native:change', (e) => {
    console.log('Page:', e.detail.value);
  });
</script>

Disabled

<n-pagination total="10" value="5" disabled></n-pagination>

API

Attributes

AttributeTypeDefaultDescription
totalnumber1Total number of pages.
valuenumber1Current page number (1-based).
siblingsnumber1Number of sibling pages shown around the current page.
boundariesnumber1Number of boundary pages shown at start and end.
disabledbooleanfalseDisables all pagination buttons. Sets aria-disabled="true".
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.

Events

EventDetailDescription
native:change{ value }Fired when the page changes.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state on the container.
[aria-current="page"]Highlights the current page button.

Keyboard

KeyAction
TabMove focus between page buttons.
Enter / SpaceNavigate to the focused page.

Accessibility

PropertyValue
Rolenavigation (via ElementInternals)
aria-label"Pagination" (default, overridable via attribute)
Page buttonsEach page button has aria-label="Page N". Prev/Next have aria-label="Previous page"/"Next page".
Current pagearia-current="page" on the active page button.
