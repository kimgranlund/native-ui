<n-radio-group> + <n-radio>

Exclusive single-select radio group with roving focus, form association, and arrow-key navigation.

  <n-radio value="banana">Banana</n-radio>

</n-radio-group>

API

Attributes — <n-radio-group>

AttributeTypeDefaultDescription
valuestring—Currently selected radio value.
disabledbooleanfalseDisables all radios in the group.
requiredbooleanfalseMarks as required for form validation.
namestring—Form field name.
orientation"vertical" | "horizontal""vertical"Layout direction of radio items.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Attributes — <n-radio>

AttributeTypeDefaultDescription
valuestring""Radio value emitted on selection.
disabledbooleanfalseDisables this individual radio.

Events

EventDetailDispatched byDescription
native:change{ value, label }n-radio-groupFired when the selected radio changes.
native:select{ value, label }n-radioFired on individual radio click (internal, caught by group).

CSS Selectors

SelectorDescription
[aria-checked="true"]Selected radio.
[aria-checked="false"]Unselected radio.
[aria-disabled="true"]Disabled state.
[pressed]Present while pointer or key is held down.
[force-hover]Forces hover appearance for debugging/testing.
[force-active]Forces active appearance for debugging/testing.
[force-focus-visible]Forces focus ring for debugging/testing.

Keyboard

KeyAction
ArrowDown / ArrowRightMoves to next radio and selects it.
ArrowUp / ArrowLeftMoves to previous radio and selects it.
Enter / SpaceSelects the focused radio.
