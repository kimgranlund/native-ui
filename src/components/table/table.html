API

Attributes (n-table)

AttributeTypeDefaultDescription
selectablebooleanfalseEnables row selection on click.
resizablebooleanfalseEnables column resize handles on header cells.
reorderablebooleanfalseEnables drag-to-reorder rows.
colsstring—Sets grid-template-columns (e.g. "auto auto 1fr").
sticky-headerbooleanfalseMakes the header row sticky on scroll. Measures header height for colspan positioning.
sticky-columnbooleanfalseMakes the first column sticky on horizontal scroll. CSS-only.
variant"plain"—Plain variant: no outer border, no radius, no header fill, no row hover.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Attributes (n-table-header)

AttributeTypeDefaultDescription
sortablebooleanfalseEnables click-to-sort on this column.
sort"none" | "asc" | "desc""none"Current sort state (managed by n-table store).

Attributes (n-table-row)

AttributeTypeDefaultDescription
valuestring—Row identifier used for selection tracking.
selectedbooleanfalseWhether this row is selected (managed by n-table store).
colspanbooleanfalseFull-width category header row. Hidden when sorting is active.
stickybooleanfalseMakes a colspan row sticky below the header (requires sticky-header).

Events

EventDetailDescription
native:table-sort{ column, direction }Fired when sort changes. direction: "asc", "desc", or null.
native:table-select{ value, selected, allSelected }Fired when row selection changes. allSelected is an array of all selected values.

CSS Selectors

SelectorDescription
[aria-selected="true"]Selected row. Highlighted background.
[aria-sort="ascending"]Column header sorted ascending.
[aria-sort="descending"]Column header sorted descending.
[resizing]Present on the table during column resize.
[dragging]Present on the row being dragged during reorder.
[force-hover]Forces hover on rows for debugging/testing.
[force-focus-visible]Forces focus ring on selectable rows for debugging/testing.

Keyboard

KeyAction
TabMove focus between interactive elements (sort headers, selectable rows).
Enter / SpaceToggle sort on a sortable header, or select a row.
