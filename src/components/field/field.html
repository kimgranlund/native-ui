<n-field>

Form field wrapper with label, description, error message, and ARIA wiring.

Basic

We'll never share your email. 
<n-field>
  <label slot="label">Email address</label>
  <n-input placeholder="you@example.com"></n-input>
  <span slot="description">We'll never share your email.</span>
</n-field>

Required

As it appears on your ID. 
<n-field required>
  <label slot="label">Full name</label>
  <n-input placeholder="Jane Doe"></n-input>
  <span slot="description">As it appears on your ID.</span>
</n-field>

With Error

Username is already taken. Your personal website or blog. Please enter a valid URL. 
<n-field required invalid>
  <label slot="label">Username</label>
  <n-input placeholder="Choose a username" invalid></n-input>
  <span slot="error">Username is already taken.</span>
</n-field>

API

Attributes

AttributeTypeDefaultDescription
disabledbooleanfalseCascades disabled state to the child control. Sets aria-disabled="true" on the field.
requiredbooleanfalseCascades required state to the child control. Shows asterisk after label.
invalidbooleanfalseSet automatically on native:invalid event. Shows the error slot.
gap"none" | "tight" | "relaxed"—Vertical gap between label, control, and description.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

Slots

SlotDescription
labelField label text. Wired to the control via aria-labelledby.
descriptionHelp text below the control. Wired via aria-describedby.
errorError message, hidden until [invalid] is set. Added to aria-describedby when visible.
(default)The form control (n-input, n-select, n-checkbox, etc.).

Events (listened)

EventDetailDescription
native:invalid{ message? }Sets [invalid] and updates error slot text.
native:valid—Removes [invalid] and error from aria-describedby.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state. Label and description show disabled color.
[invalid]Validation error state. Shows the error slot.
[required]Required state. Appends asterisk to label.

Accessibility

PropertyValue
ARIA wiringAuto-wires aria-labelledby and aria-describedby on the child control.
Control discoveryFinds the first unslotted form control (n-input, n-select, n-checkbox, etc.).
