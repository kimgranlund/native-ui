<n-video>

CSS-only video container with token-aware border-radius, responsive sizing, and a --n-control background placeholder.

Basic

<n-video>
  <video controls>
    <source src="clip.mp4" type="video/mp4">
  </video>
</n-video>

Border Radius

radius="sharp"
radius="round"
radius="pill" 
<n-video radius="sharp">
  <video controls>...</video>
</n-video>

  <video controls>...</video>
</n-video>

<n-video radius="pill">
  <video controls>...</video>
</n-video>

Placeholder Background

With no video loaded, the --n-control background is visible as a placeholder. 
<n-video style="aspect-ratio: 16/9;">
  <!-- Placeholder: shows --n-control background -->
</n-video>

Inside a Container

Tutorial Video

A short walkthrough of the setup process. 
<n-container>
  <n-video>
    <video controls>
      <source src="tutorial.mp4" type="video/mp4">
    </video>
  </n-video>
  <div class="body">
    <h3>Tutorial Video</h3>
    <span class="text" muted>Description.</span>
  </div>
</n-container>

API

Attributes

AttributeTypeDefaultDescription
radius"sharp" | "round" | "pill"inheritedBorder radius preset. Inherits --n-radius.

CSS Custom Properties

PropertyDefaultDescription
--n-radiusinheritedBorder radius applied to the container. Clips the child video.
--n-controlinheritedBackground color shown when no video is loaded.
