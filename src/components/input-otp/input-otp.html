API

Attributes

AttributeTypeDefaultDescription
valuestring""Current OTP value.
lengthnumber6Number of cells (1-12).
disabledbooleanfalseDisables interaction. Sets aria-disabled="true".
requiredbooleanfalseMarks as required for form validation.
namestring—Form field name for submission.
patternstring"[0-9]"Regex pattern for allowed characters per cell.
maskstring—Mask character for display (e.g. "*"). Shows dots instead of entered characters.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
radius"sharp" | "default" | "round"inheritedBorder radius. CSS-only.

Events

EventDetailDescription
native:input{ value }Fired on each cell change.
native:change{ value }Fired when all cells are filled.

CSS Selectors

SelectorDescription
[aria-disabled="true"]Disabled state.
[force-hover]Forces hover appearance on cells for debugging/testing.
[force-focus]Forces focus appearance on cells for debugging/testing.

Keyboard

KeyAction
0-9Enter digit and auto-advance to next cell.
BackspaceClear current cell, or move to previous cell if empty.
DeleteClear current cell.
ArrowLeftMove to previous cell.
ArrowRightMove to next cell.
PasteDistributes pasted text across cells (filtered by pattern).

PropertyValue
