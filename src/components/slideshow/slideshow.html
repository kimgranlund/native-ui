API


    

      
Attributes

      

        
AttributeTypeDefaultDescription

        
          
direction"horizontal" | "vertical""horizontal"Scroll direction of the carousel.

          
controlsbooleanfalseShows prev/next navigation buttons.

          
indicatorsbooleanfalseShows dot indicators below slides.

          
autoplaybooleanfalseEnables automatic slide advancement. Pauses on hover/focus. Respects prefers-reduced-motion.

          
intervalnumber5000Autoplay interval in milliseconds.

          
loopbooleanfalseEnables infinite looping (wraps from last to first and vice versa).

          
peekbooleanfalseShows partial adjacent slides at the edges.

          
per-viewnumber1Number of slides visible at once.

          
gapbooleanfalseAdds spacing between slides.

          
indexnumber0Active slide index (0-based). Setting navigates to that slide.

          
disabledbooleanfalseDisables keyboard navigation. Sets aria-disabled="true".

          
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.

          
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.

        
      

    


    

      
Events

      

        
EventDetailDescription

        
          
native:slide-change{ index, slide }Fired when the active slide changes (via scroll snap, controls, or API).

        
      

    


    

      
CSS Selectors

      

        
SelectorDescription

        
          
[aria-disabled="true"]Disabled state. Disables track interaction and dims controls.

          
[force-hover]Forces hover appearance on controls and indicators.

          
[force-focus-visible]Forces focus ring on controls and indicators.

          
n-slide[active]Present on the currently visible slide.

        
      

    


    

      
Keyboard

      

        
KeyAction

        
          
ArrowRight / ArrowDownNext slide (direction-dependent).

          
ArrowLeft / ArrowUpPrevious slide (direction-dependent).

          
HomeGo to first slide.

          
EndGo to last slide.
