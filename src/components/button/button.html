Justify: spread

Favorites Edit Profile justify="spread" switches to auto 1fr auto columns so the label fills available space and trailing icon pushes to the far edge. Used as dropdown triggers in <n-select>. 
<n-button justify="spread">
  <n-icon name="heart" slot="leading"></n-icon>
  <span slot="label">Favorites</span>
  <n-icon name="arrow-right" slot="trailing"></n-icon>
</n-button>

API

Attributes

AttributeTypeDefaultDescription
disabledbooleanfalseDisables interaction. Sets aria-disabled="true" and removes from tab order.
type"button" | "submit" | "reset""button"Form button type. submit calls form.requestSubmit(), reset calls form.reset().
variant"primary" | "secondary" | "outline" | "ghost" | "default" | "selected""default"Visual variant. CSS-only, no JS.
intent"neutral" | "accent" | "info" | "success" | "warning" | "danger"inheritedColor intent. CSS-only, cascades from parent.
size"xs" | "sm" | "md" | "lg" | "xl"inheritedSize scale. CSS-only, cascades from parent.
density"compact" | "default" | "loose"inheritedInline padding density. CSS-only, cascades from parent.
radius"sharp" | "default" | "round""round"Border radius. CSS-only.
justify"spread"—Switches grid to auto 1fr auto columns. Used for dropdown triggers in <n-select>.
inlinebooleanfalseShrink-wraps the button instead of filling available width.

Slots

SlotDescription
leadingLeading icon or element (before label).
labelButton text label.
trailingTrailing icon or element (after label).
(default)Unslotted content — used for icon-only buttons.

Events

EventDetailDescription
native:press{ pointerType }Fired on activation (click, Enter, Space). pointerType: "mouse", "touch", "pen", or "keyboard".

CSS Selectors

SelectorDescription
[pressed]Present while pointer or key is held down.
[aria-disabled="true"]Disabled state. Use for custom disabled styling.
[force-hover]Forces hover appearance for debugging/testing.
[force-active]Forces active appearance for debugging/testing.
[force-focus-visible]Forces focus ring for debugging/testing.

Keyboard

KeyAction
EnterActivates the button.
SpaceActivates the button (on key up).
