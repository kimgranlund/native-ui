<n-noodles>

Declarative SVG noodle canvas. Children declare ports via data-noodle-port and the element handles the SVG overlay, coordinate system, and stacking context automatically.

Basic (static connections)

Source
Filter
Transform
Display 
<n-noodles>
  <div id="src" data-noodle-port="right">Source</div>
  <div id="filter" data-noodle-port="left right">Filter</div>
  <div id="display" data-noodle-port="left">Display</div>
</n-noodles>

<script>
  const canvas = document.querySelector('n-noodles');
  canvas.connect('src', 'filter', 'right', 'left');
  canvas.connect('filter', 'display', 'right', 'left');
</script>

Editable (drag-to-connect)

Drag from a port dot to connect. Grab near a noodle endpoint to reconnect. Drop outside to disconnect.

  <div id="input" data-noodle-port="right bottom">Input</div>
  <div id="validate" data-noodle-port="left right top bottom">Validate</div>
  <div id="output" data-noodle-port="left top">Output</div>
</n-noodles>

API Reference

Attributes

AttributeTypeDefaultDescription
editablebooleanfalseAllow interactive creation/deletion of connections
colorstringaccentNoodle stroke color
stroke-widthnumber2Stroke width in px
tensionnumber0.5Bezier control point distance (0–1)
show-portsbooleanautoShow port indicator dots (defaults to editable)
port-sizenumber10Port dot size in px
curvestringbezierCurve style: bezier, step, straight
animatedbooleanfalseFlowing dash animation on noodles
disabledbooleanfalseDisable the controller

Properties & Methods

MemberTypeDescription
.connectionsNoodleConnection[]Current connections (read-only)
.connect(from, to, fromPort?, toPort?)stringCreate a connection, returns ID
.disconnect(id)booleanRemove a connection by ID
.setConnections(arr)voidReplace all connections
.clear()voidRemove all connections
.update()voidForce re-render

Events

EventDetailDescription
native:noodle-connect{ id, from, to, fromPort, toPort }Connection created
native:noodle-disconnect{ id, from, to, fromPort, toPort }Connection removed
native:noodle-drag{ from, fromPort, x, y }Pointer moves during drag

Port Declaration

Children declare connectable ports via the data-noodle-port attribute with space-separated sides:

<div id="node-1" data-noodle-port="left right top bottom">...</div>
