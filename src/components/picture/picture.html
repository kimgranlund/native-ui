<n-picture>

CSS-only image container with token-aware border-radius, responsive sizing, object-fit control, and aspect ratio presets.

Basic

<n-picture>
  <img src="photo.jpg" alt="Sample image" />
</n-picture>

Object Fit

fit="cover" (default)
fit="contain"
fit="fill"
fit="none" 
<n-picture fit="cover">...</n-picture>
<n-picture fit="contain">...</n-picture>
<n-picture fit="fill">...</n-picture>
<n-picture fit="none">...</n-picture>

Aspect Ratio

aspect="square" (1:1)
aspect="video" (16:9)
aspect="photo" (4:3) 
<n-picture aspect="square">...</n-picture>
<n-picture aspect="video">...</n-picture>
<n-picture aspect="photo">...</n-picture>

Border Radius

radius="sharp"
radius="round"
radius="pill" 
<n-picture radius="sharp">...</n-picture>
<n-picture radius="round">...</n-picture>
<n-picture radius="pill" aspect="square">...</n-picture>

Inline Mode

Text before text after the inline image. 

<p>
  Text before
  <n-picture inline style="width: 4rem;">
    <img src="photo.jpg" alt="Inline" />
  </n-picture>
  text after.
</p>

  </n-picture>
  <div class="body">
    <h3>Ocean Sunset</h3>

  </div>

API

Attributes

AttributeTypeDefaultDescription
fit"cover" | "contain" | "fill" | "none"coverControls object-fit on the child <img>.
aspect"square" | "video" | "photo"noneConstrains the image to a fixed aspect ratio. square = 1:1, video = 16:9, photo = 4:3.
inlinebooleanfalseSwitches from block to inline-block display.
radius"sharp" | "round" | "pill"inheritedBorder radius preset. Inherits --n-radius.

CSS Custom Properties

PropertyDefaultDescription
--n-radiusinheritedBorder radius applied to the container. Clips the child image.
