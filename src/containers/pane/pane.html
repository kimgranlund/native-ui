<n-pane>

AttributeTypeDefaultDescription
labelstring—Header label text
iconstring—Phosphor icon name
closeablebooleanfalseShows close button
minimizablebooleanfalseShows minimize/restore button
minimizedbooleanfalseCollapsed to header-only
sizestringautoInitial main-axis size (e.g. "300px", "33%", "20rem")
size-minnumber0Minimum size in px
size-maxnumber∞Maximum size in px
scrollableboolean | "x" | "y" | "both"—Overflow scrolling on the pane
borderedbooleanfalseAdds border around pane
