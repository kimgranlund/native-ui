<n-body>

Scrollable content region that fills remaining flex space. CSS-only container — no JavaScript. Used inside <n-container>, <n-drawer>, or any flex column parent.

Basic

Card Title

The body fills all remaining vertical space in a flex column. It has default padding from the spacing scale.

 
<n-container>
  <n-header><span>Card Title</span></n-header>
  <n-body>
    <p>Content fills remaining space.</p>
  </n-body>
</n-container>

Scrollable Content

When the parent container has a fixed height, <n-body> scrolls independently while siblings (<n-header>, <n-footer>) stay pinned. The scrollbar is hidden by default.

Scrollable Card

This card has a fixed height. The body scrolls independently while the header and footer stay pinned.

Padding Scale

The [padding] attribute overrides the default spacing. Available values: none, tight, regular, relaxed.

padding="none"

No padding. Content touches the edges.

 padding="tight"

Tight padding. Compact spacing for dense layouts.

 (default)

Default padding. Balanced for general content.

 padding="regular"

Regular padding. More breathing room.

 padding="relaxed"

Relaxed padding. Maximum spaciousness.

 
<n-body padding="none">...</n-body>
<n-body padding="tight">...</n-body>
<n-body>...</n-body>                <!-- default -->
<n-body padding="regular">...</n-body>
<n-body padding="relaxed">...</n-body>

Standalone (No Header/Footer)

<n-body> works on its own as a flex-grow content region. Without a height-constrained parent, it simply fills available space without scrolling.

Standalone body inside a flex column. Fills all available vertical space.

 
<div style="display: flex; flex-direction: column; height: 12rem;">
  <n-body>
    <p>Fills all available space.</p>
  </n-body>
</div>

Rich Content

<n-body> is a flex column with gap, so child elements space evenly. Use it for forms, lists, or mixed content.

API

Attributes

AttributeTypeDefaultDescription
show-scrollbarbooleanfalseShows a thin scrollbar when content overflows. Default hides the scrollbar.
padding"none" | "tight" | "regular" | "relaxed"defaultPadding scale override. Default uses --n-space * --n-space-k.

CSS Custom Properties

PropertyDefaultDescription
--n-padding-blockcalc(var(--n-space) * var(--n-space-k))Vertical padding.
--n-padding-inlinecalc(var(--n-space) * var(--n-space-k))Horizontal padding.

Behavior

ContextBehavior
Inside <n-container> with <n-header> or <n-footer>Gets overflow-y: auto and scrollbar-width: none. Parent sets overflow: hidden to delegate scrolling.
Inside <n-container data-kind="panel">Gets flex column layout with gap and padding from the spacing scale.
Inside <n-drawer>Drawer delegates overflow to body so header/footer stay fixed.
StandaloneFills remaining flex space (flex: 1 1 0%). No scrolling unless parent constrains height.
