<n-header> / <n-body> / <n-footer>

Composable sub-containers for structuring surfaces. CSS-only. Work inside n-container, n-drawer, article[data-kind="panel"], or any flex column.

n-header — Basic

Card Title

Body content with the default padding and scrollable overflow.

 
<n-container>
  <n-header>
    <span>Card Title</span>
  </n-header>
  <n-body>
    <p>Body content here.</p>
  </n-body>
</n-container>

n-header — Truncate

[truncate] adds text-overflow ellipsis to the label slot. Useful for long titles in fixed-width containers.

This is a very long title that will overflow and wrap to multiple lines

Default — label wraps.

 This is a very long title that will be truncated with an ellipsis

With [truncate] — ellipsis.
Document with a very long name that needs truncation

With slots — label truncates while leading/trailing stay visible.

 
<n-header truncate>
  <span>Very long title...</span>
</n-header>
