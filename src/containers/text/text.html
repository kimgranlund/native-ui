<n-text>

CSS-only utility element for styled text blocks — muted descriptions, secondary labels, section intros. No JS registration needed.

Basic

This is a default n-text element. It renders as a block-level paragraph with the inherited font size, line height, and ink color. 
<n-text>This is a default n-text element.</n-text>

Sizes

Extra small (xs) Small (sm) Medium (md) — same as default Large (lg) Extra large (xl) 
<n-text size="xs">Extra small (xs)</n-text>
<n-text size="sm">Small (sm)</n-text>
<n-text size="md">Medium (md)</n-text>
<n-text size="lg">Large (lg)</n-text>
<n-text size="xl">Extra large (xl)</n-text>

Color Modifiers

Default ink color Muted — secondary, de-emphasized text Strong — bold, high-contrast text 
<n-text>Default ink color</n-text>
<n-text muted>Muted — secondary, de-emphasized text</n-text>
<n-text strong>Strong — bold, high-contrast text</n-text>

Inline Mode

This is regular text with inline muted text mixed in, and also inline strong text alongside it.

<p>This is regular text with
  <n-text inline muted>inline muted</n-text> text mixed in,
  and also <n-text inline strong>inline strong</n-text> text
  alongside it.</p>

Spacing

Tight spacing — smaller bottom margin
Regular spacing — medium bottom margin
Relaxed spacing — large bottom margin 
<n-text spacing="tight">Tight spacing</n-text>
<n-text spacing="regular">Regular spacing</n-text>
<n-text spacing="relaxed">Relaxed spacing</n-text>

Truncate

This is a very long line of text that will be truncated with an ellipsis when it overflows the container boundary. 
<div style="max-width: 20rem;">
  <n-text truncate>This is a very long line of text that
    will be truncated with an ellipsis...</n-text>
</div>
