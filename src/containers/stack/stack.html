<n-stack>

Flex layout utility. Vertical or horizontal stacking with configurable gap, alignment, and wrapping. CSS-only container.

Composition (with components)

Form layout

Remember me Sign In 
<n-stack gap="4">
  <n-input placeholder="Email address"></n-input>
  <n-input placeholder="Password" type="password"></n-input>
  <n-stack direction="row" justify="spread" align="center">
    <n-checkbox>Remember me</n-checkbox>
    <n-button variant="primary" intent="accent">Sign In</n-button>
  </n-stack>
</n-stack>

Button group

Save Cancel Delete 
<n-stack direction="row" gap="2">
  <n-button variant="primary" intent="accent">Save</n-button>
  <n-button>Cancel</n-button>
  <n-button variant="ghost" intent="danger">Delete</n-button>
</n-stack>

API

Attributes

AttributeTypeDefaultDescription
direction"row" | "column-reverse" | "row-reverse"columnFlex direction. Default is vertical stacking.
gap"0" | "1" | "2" | "3" | "4" | "6" | "8""2"Gap multiplier (--n-space * N).
wrapbooleanfalseEnables flex wrapping.
justify"start" | "center" | "end" | "spread" | "around" | "evenly"startJustify content along the main axis.
align"start" | "center" | "end" | "stretch" | "baseline"stretchAlign items along the cross axis.
padding"none" | "tight" | "regular" | "relaxed""none"Padding scale.
sticky"top" | "bottom"noneSticks the stack to the top or bottom of the scroll container.
truncatebooleanfalseTruncates child text with ellipsis (excludes nav/aside).
dividersbooleanfalseAdds horizontal divider borders between children.

Adaptive Grid Slots

Child ElementDescription
<nav>Leading slot. When present, stack auto-switches to grid layout.
<aside>Trailing slot. When present, stack auto-switches to grid layout.

CSS Custom Properties

PropertyDefaultDescription
--n-padding-block0Vertical padding.
--n-padding-inline0Horizontal padding.
