<n-inset>

Content indentation container. Adds consistent inline-start padding without visual surface. CSS-only container.

Basic

Parent heading Indented child 1 Indented child 2 Indented child 3 
<span>Parent heading</span>
<n-inset>
  <span>Indented child 1</span>
  <span>Indented child 2</span>
  <span>Indented child 3</span>
</n-inset>

Nested Checkboxes

Select all Option A Option B Option C 
<n-checkbox checked>Select all</n-checkbox>
<n-inset>
  <n-checkbox checked>Option A</n-checkbox>
  <n-checkbox checked>Option B</n-checkbox>
  <n-checkbox>Option C</n-checkbox>
</n-inset>

lg parent lg indented content
