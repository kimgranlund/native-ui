API

Attributes

AttributeTypeDefaultDescription
data-kind"panel"cardElevation mode. Default is card elevation. "panel" uses panel elevation with auto padding and gap.
borderedbooleanfalseAdds a subtle border (--n-border-muted).
interactivebooleanfalseMakes the container focusable and clickable with hover/focus states.
hrefstringnoneNavigation URL when clicked (requires interactive).
inlinebooleanfalseSwitches from flex-grow to shrink-wrap sizing.
dividersbooleanfalseAdds horizontal divider borders between direct children.
scrollablebooleanfalseEnables vertical scrolling (panel mode only).
show-scrollbarbooleanfalseShows a thin scrollbar (panel mode only).
fadebooleanfalseApplies gradient fade masks to body edges (panel mode only).
size"xs" | "sm" | "md" | "lg" | "xl""md"Size context inherited by children (spacing, font, icon).
intent"accent" | "info" | "success" | "warning" | "danger"neutralSemantic color intent.
radius"sharp" | "round" | "pill"inheritedBorder radius preset.

Slots

SlotDescription
mediaFull-width image or media region at the top of the container.
(default)Body content. Use <n-header>, <n-body>, <n-footer> for structured layout.

CSS Custom Properties

PropertyDefaultDescription
--n-groundvar(--n-card)Background color. Panel mode uses var(--n-panel).
--n-ground-hovervar(--n-card-hover)Hover background (interactive mode).
--n-radiusinheritedBorder radius.
