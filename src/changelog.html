Changelog

Version history for @nonoun/native-ui. Each release lists new features, updates, and breaking changes with links to relevant demo pages.

0.7.0 — March 2026

New New Features

  • <n-text> — CSS-only utility element for styled text blocks (muted, strong, sizes, truncate, spacing). Demo
  • SlashCommandController — detects / prefix in inputs, shows filtered command listbox popover. Demo
  • <n-panel> [fade] attribute — fades top/bottom edges when content overflows. Demo
  • <n-panel> [scrollable] attribute — opt-in overflow scrolling (replaces implicit overflow). Demo

Updated Updates

  • <n-toolbar> — overflow priority (overflow-priority), pin (overflow-pin), and diagnostics (native:toolbar-overflow event). Demo
  • <n-header> — [truncate] attribute for label text truncation with ellipsis. Demo
  • <n-textarea> — inline formatting support (formatting="code bold italic"). Demo
  • ResizeController — corner resize handles for diagonal resizing. Demo

Breaking Changes

  • <n-panel> overflow is now opt-in via [scrollable]. Panels that relied on implicit overflow: auto must add the attribute.

0.6.6 — February 2026

  • Added CDN setup via esm.sh, signal/trait/OKLCH/variant examples to docs.
  • Bumped all package versions to 0.6.6.
