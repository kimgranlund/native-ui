0.7.44 — March 2026

New Fun Traits (6 total)

TossController — Physics-based throwing

Pick up an element and fling it with momentum.

  • Configurable friction, gravity, and optional viewport edge bouncing with damping
  • Spin mode tracks angular velocity from horizontal pointer movement
  • returnOnEnd animates back to origin after momentum settles
 Events: native:toss native:bounce CSSInspectController — 3D layer inspector

Hover to explode child layers in 3D space with interactive mouse-tracking tilt.

  • Recursive DOM walking labels every descendant via [data-inspect-label]::after
  • Pick mode (Alt+hover) inspects individual elements in large containers
  • Clone-in-popover rendering escapes ancestor clipping and preserve-3d flattening
  • Popover-based highlight overlays for pre-inspection hover (escapes overflow clipping)
  • Scroll wheel zoom controls z-depth multiplier during inspection
  • Selection interception blocks text selection and drag-to-select while inspecting
 Events: native:inspect FlipController — 3D card flip

Flip on click or hover with CSS 3D transforms.

  • Configurable axis (X/Y), duration, and perspective
  • Front/back faces via [data-flip-back] with automatic backface-visibility
  • Programmatic flip(), unflip(), toggle() API
 Events: native:flip ParallaxController — Holographic tilt

Mouse-position tilt effect — like holographic trading cards.

  • Tracks pointer relative to element center → perspective + rotateX + rotateY + scale
  • Optional glare overlay via radial gradient that follows the cursor
  • Exposes --parallax-tilt-x / --parallax-tilt-y CSS custom properties for CSS-driven effects
 Events: native:parallax-move ConfettiController — Particle burst

DOM-based confetti particles with randomized trajectories.

  • Physics: gravity, air resistance, rotation, and fade-out
  • Configurable count, spread, velocity, shapes (square/circle/mixed), and colors
  • Multiple concurrent bursts supported — each gets its own overlay
 Events: native:confetti MagnetController — Snap-to-grid drag

Elements snap toward each other or to a grid when dragged within a threshold.

  • Three snap modes: grid lines, sibling edges/centers, container edges
  • Strength-based easing into snap position (not hard snapping)
  • Visual guide lines appear during active snap
 Events: native:magnet-snap native:magnet-drop

Breaking Trait Option Namespace

Trait option attributes renamed to data-trait-*

All trait option attributes now use data-trait-{name}-{key} prefix instead of bare {name}-{key}. This prevents namespace collisions between trait options and component API attributes on self-trait elements.

  • Example: draggable-axis="vertical" → data-trait-draggable-axis="vertical"
  • Affects all <n-controller> option attributes and self-trait usage
  • Updated all 30 trait demo pages, 3 doc files, and CLAUDE.md

Updated Fixes

Demo and navigation fixes
  • Fixed broken n-layout.ts imports in tossable.html, shortcutable.html demo pages
  • Added Updates sidebar group — highlights recent additions at the top of the navigation

0.7.37 — March 2026

New A2UI Session Layer (@nonoun/native-ai 0.2.2)

Session Manager + Surface Registry
  • Session Manager — NSessionManager creates and manages agent sessions with event emitters, surface ownership, and component catalogs
  • Surface Registry — NSurfaceRegistry manages named render targets with single-owner semantics and ownership transfer
  • Component Catalog — buildCatalogFromRegistry() builds typed catalogs from the kernel's component registry
 Protocol Adapters

Bridge external agent protocols to the A2UI surface system.

  • DirectAdapter — In-process adapter for local agents (simulation, testing)
  • A2AAdapter — Google A2A protocol adapter (agent-to-agent task delegation)
  • AgUIAdapter — AG-UI protocol adapter (agent-generated UI streaming)

New A2A Demo Pages

A2A Tic-Tac-Toe

Two AI agents (Claude vs ChatGPT) play Tic-Tac-Toe through independent A2UI surfaces.

  • Human play via cell click, simulation mode with minimax AI, auto-play with disabled controls
  • Pulsing outline turn indicators, animated icon transitions, click-to-start game creation
  • Model selection: Claude Haiku 4.5, GPT-5 mini/nano, GPT-4.1 mini/nano, Human
 Session lifecycle demos
  • A2A Sessions — Create, pause, resume, terminate sessions with status transitions and event log
  • A2A Ownership — Surface ownership transfer between competing agents
  • A2A Catalog — Component catalog explorer with rendering capabilities

Enhanced Sub-Container Padding Alignment

Consistent padding scale across header, body, footer
  • <n-header> — Default --n-header-padding-block changed from space × 2 to space × 4, matching <n-footer>
  • <n-footer> — Variants aligned: tight block space × 2 / inline space × 4, regular block space × 4 / inline space × 6, relaxed block space × 6 / inline space × 8
  • <n-body> — Default: space × 4 block and inline. Variants aligned to same scale
  • All three use identical min-height: calc(var(--n-size) + total-block-padding) math

Enhanced Component CSS Fixes

Button, input, select, card, stack fixes
  • <n-button> — Added max-height: var(--n-size) to prevent vertical stretching in flex containers
  • <n-input> — Added max-height: var(--n-size), same vertical containment fix
  • <n-select> popover — Removed inline margin that caused trigger/dropdown misalignment
  • <n-card> — Gap token changed from calc(var(--n-space) * 0) to explicit 0
  • <n-stack> — Default flex changed from 1 1 100% to 1 1 0% (standard flex-grow)

Enhanced Lifecycle Hardening

NativeElement, NController, DragController
  • NativeElement ready — Renewable promise, fresh on each connectedCallback. #pendingDefers counter gates readiness
  • deferChildren — Sync check → microtask → RAF → RAF (3 attempts) for slow CE upgrades
  • #alive guard — Prevents double-setup on rapid DOM moves, respects _reparenting flag
  • NController — Calls renewReady() in own connectedCallback. #retryApplyFirstChild for wrapper mode
  • DragController — Listener cleanup ordering prevents re-entry and navigation leaks

Enhanced Token & Color Changes

Popover margin, ink-inverse, shared control defaults
  • --n-popover-viewport-margin — No longer applied to select/combobox dropdown inline margins
  • --n-ink-inverse — Documented: resolves to raw darkest ramp step, never flips with theme
  • n-components.shared.css — Updated shared control defaults

New New Package

<n-chart> — SVG charting component

Pure math scale system, keyed SVG reconciliation, reactive store, CSS token integration.

  • Chart types: line (smooth, area fill), bar (grouped, stacked), scatter (variable radius), sparkline (inline)
  • Scale system: LinearScale, TimeScale, BandScale — auto-detected from data
  • Interactions: crosshair tracking, binary-search bisect, popover tooltip with viewport flipping, legend toggling
  • Data loading: src attribute fetches JSON, data property for programmatic use
  • Color palette: 6 OKLCH families at steps 500 and 300 — auto-adapts to light/dark mode
 Events: native:chart-hover native:chart-select native:chart-legend-toggle
