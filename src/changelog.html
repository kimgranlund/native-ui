Changelog

Version history for @nonoun/native-ui. Each release lists new features, updates, and breaking changes with links to relevant demo pages.

0.7.43 — March 2026

New Fun Traits

  • TossController — Pick up an element, fling it with momentum. Physics-based deceleration with configurable friction, gravity, spin (angular velocity from horizontal pointer movement), and optional viewport edge bouncing with damping. Events: native:toss (momentum end), native:bounce (each edge hit). Options: friction, bounce, bounceDamping, gravity, spin, returnOnEnd.
  • CSSInspectController — Hover to explode child layers in 3D space with interactive mouse-tracking tilt. Recursive DOM walking labels every descendant with tag name via [data-inspect-label]::after. Smooth 500ms explosion transition followed by 60ms responsive tilt. Options: depth, scale, rotateX, rotateY, tiltStrength, perspective, labels, recursive.

Updated Fixes

  • Fixed broken n-layout.ts imports in tossable.html, shortcutable.html demo pages — corrected to native-app.ts / <native-app-spa>.
  • Added Updates sidebar group — highlights recent additions at the top of the navigation for quick discovery.

0.7.37 — March 2026

New A2UI Session Layer (@nonoun/native-a2ui 0.2.2)

  • Session Manager — NSessionManager creates and manages agent sessions. Each session is an AgentSession with its own event emitter, surface ownership, and component catalog.
  • Surface Registry — NSurfaceRegistry manages named render targets (DOM mount points). Surfaces have single-owner semantics: only the owning session can write to a surface. Ownership can be transferred between sessions.
  • Component Catalog — buildCatalogFromRegistry() builds a typed catalog of available A2UI components from the kernel's component registry. Catalogs are passed to sessions to constrain what components agents can render.
  • Adapters — Protocol adapters bridge external agent protocols to the A2UI surface system:
    • DirectAdapter — In-process adapter for local agents (simulation, testing).
    • A2AAdapter — Google A2A protocol adapter (agent-to-agent task delegation).
    • AgUIAdapter — AG-UI protocol adapter (agent-generated UI streaming).
  • Event Emitter — Lightweight typed event emitter for session lifecycle events (status-change, error, component-update).
  • Tests — 5 test suites covering catalog, direct adapter, event emitter, session manager, and surface registry.

New A2A Demo Pages

  • A2A Tic-Tac-Toe — Two AI agents (Claude vs ChatGPT) play Tic-Tac-Toe through independent A2UI surfaces. Features: human play via cell click, simulation mode with minimax AI, auto-play with disabled controls, pulsing outline turn indicators, animated icon transitions, click-to-start game creation, model selection (Claude Haiku 4.5, GPT-5 mini/nano, GPT-4.1 mini/nano, Human).
  • A2A Sessions — Session lifecycle demo: create, pause, resume, terminate sessions. Shows status transitions and event log.
  • A2A Ownership — Surface ownership transfer demo: two agents competing for write access to a shared surface, ownership gating, transfer mechanics.
  • A2A Catalog — Component catalog explorer: browse available A2UI components, their properties, and rendering capabilities.

Enhanced Sub-Container Padding Alignment

  • <n-header> — Default --n-header-padding-block changed from space × 2 to space × 4, matching <n-footer>. All padding variants (tight, regular, relaxed) now use the same scale across header, body, and footer.
  • <n-footer> — Padding variants aligned to consistent scale. tight: block space × 2, inline space × 4. regular: block space × 4, inline space × 6. relaxed: block space × 6, inline space × 8.
  • <n-body> — Padding variants aligned. Default: space × 4 block and inline. tight: inline space × 4. regular: block space × 4, inline space × 6. relaxed: block space × 6, inline space × 8.
  • Min-height formula — All three sub-containers now use identical min-height: calc(var(--n-size) + total-block-padding) math so headers, bodies, and footers at the same padding variant produce consistent sizing.

Enhanced Component CSS Fixes

  • <n-button> — Added max-height: var(--n-size) to base rule. Prevents buttons from stretching vertically in flex containers.
  • <n-input> — Added max-height: var(--n-size) to base rule. Same vertical containment fix.
  • <n-select> popover — Removed margin-inline: var(--n-popover-viewport-margin) from the popover listbox positioning rule. This was causing a visible inset/misalignment between the trigger button and the dropdown.
  • <n-card> — Gap token changed from calc(var(--n-space) * 0) to explicit 0.
  • <n-stack> — Default flex changed from 1 1 100% to 1 1 0% (standard flex-grow behavior, prevents 100% flex-basis from forcing overflow).

Enhanced Lifecycle Hardening

  • NativeElement ready promise — Renewable: getter returns #readyPromise, fresh on each connectedCallback. Old promise stays resolved. #pendingDefers counter gates readiness.
  • deferChildren retries — Sync check → microtask → RAF → RAF (3 attempts). Covers slow custom element upgrades and lazy content injection.
  • #alive guard — Prevents double-setup on rapid DOM moves. disconnectedCallback respects _reparenting flag.
  • NController — Calls renewReady() in own connectedCallback (skips super). #retryApplyFirstChild for wrapper mode when first child isn't ready yet.
  • DragController — lostpointercapture listener removed before releasePointerCapture (prevents re-entry). Document listeners removed before native:drop dispatch (prevents leaks on navigation).

Enhanced Token & Color Changes

  • --n-popover-viewport-margin — No longer applied to select/combobox dropdown inline margins. Still used for block margins (top/bottom viewport safety).
  • --n-ink-inverse — Documented: resolves to --n-ink-inverse-{family} → --n-color-{family}-11 (raw darkest ramp step, never flips with theme). Used by selected state pattern for white-background pills.
  • n-components.shared.css — Updated shared control defaults.

@nonoun/native-chart 0.1.0 — March 2026

New New Package

  • <n-chart> — SVG charting component for dashboards, cards, and inline widgets. Pure math scale system, keyed SVG reconciliation, reactive store, CSS token integration.
  • Chart types: line (smooth, area fill), bar (grouped, stacked), scatter (variable radius), sparkline (inline).
  • Scale system: LinearScale, TimeScale, BandScale — auto-detected from data. Nice tick generation, SI suffix formatting, calendar-aware date ticks.
  • Interactions: crosshair tracking, binary-search bisect (nearest point), popover tooltip with viewport flipping, legend series toggling.
  • Data loading: src attribute fetches JSON, data property for programmatic use. AbortController-based fetch lifecycle.
  • Color palette: 6 OKLCH families (accent, success, warning, danger, info, neutral) at steps 500 and 300 — auto-adapts to light/dark mode.
  • Accessibility: role="img" with auto-generated aria-label, prefers-reduced-motion support, keyboard navigation.
  • Events: native:chart-hover, native:chart-select, native:chart-legend-toggle.

0.7.15 — March 2026

Enhanced Enhancements

  • ResizeController — New options: handle (external handle element), step (snap-to-grid), stateAttribute (configurable attribute name), eventTarget (redirect events). Dispatches native:resize-cancel on Escape/pointercancel. Move events include delta in detail.

0.7.13 — March 2026
