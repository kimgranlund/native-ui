Changelog

Version history for @nonoun/native-ui. Each release lists new features, updates, and breaking changes with links to relevant demo pages.

0.7.15 — March 2026

Enhanced Enhancements

  • ResizeController — New options: handle (external handle element), step (snap-to-grid), stateAttribute (configurable attribute name), eventTarget (redirect events). Dispatches native:resize-cancel on Escape/pointercancel. Move events include delta in detail.
  • <n-gripper> — Now delegates resize logic to ResizeController internally, eliminating ~150 lines of duplicated pointer lifecycle, delta calculation, and clamping code. Resizable adapter gains step option.

0.7.14 — March 2026

Enhanced Enhancements

  • <n-gripper> — Per-axis constraints: min-width, max-width, min-height, max-height for independent width/height limits in corner mode (falls back to min/max). All events now include placement in detail. Reconciled with ResizeController feature set.

0.7.13 — March 2026

New New Features

  • <n-gripper> — Declarative gripper using Popover API (top-layer rendering, escapes overflow) + CSS Anchor Positioning. Modes: resize-horizontal, resize-vertical, resize-corner. Attributes: for, placement, min, max, step, reverse, disabled. Events: native:grip-start, native:grip-move, native:grip-end, native:grip-cancel. Arrow keys nudge, Escape cancels and reverts.

0.7.11 — March 2026

Sub-Packages

  • @nonoun/native-chat@0.5.6 — popover hover toolbar (CSS anchor positioning, 150ms hover intent), 2×2 grid layout for <n-chat-messages> (context/bubbles wrapper divs, avatar spans both rows), full-bleed GenUI (bubble padding moved to content children), toolbar icons auto-registered.

0.7.8 — March 2026

New New Features

  • <n-toolbar> — orientation attribute (horizontal | vertical | both). Wires flex direction, ARIA orientation, and roving focus arrow keys.
  • lint:class-handles — new CI-ready lint script (npm run lint:class-handles) that scans JS/TS for redundant CSS class handles on custom elements.

Updated Updates

  • <n-header> — explicit grid-column placement on leading/trailing slots. Leading anchors to column 1, trailing to the last column, so they space apart even with no label content.
  • PresentController — autofocus prevention: saves and restores document.activeElement around dialog.showModal() to prevent unwanted focus shifts.
  • No-redundant-class-handles enforcement across core, native-app sidebar, native-chat, tree, and calendar.

Sub-Packages

  • @nonoun/native-a2ui@0.1.5 — JSON-IN multi-line formatting, bidirectional COMPONENTS/UI pane editing, grouped preset dropdown, single workbench instance, preset select in header leading slot.
  • @nonoun/native-app@0.3.5 — sidebar class-handle refactoring (tag-name selectors replace class selectors).
  • @nonoun/native-chat@0.5.2 — CSS selector refactoring (class-based to data-role-based selectors).

0.7.7 — March 2026

New New Features

  • PresentController — full-viewport presentation trait. Expands any element into a native <dialog> overlay with dark backdrop, optional close button, and [presented] attribute on host.
  • isTypingContext() — utility that detects if a keyboard event originated from a text-input context (input, textarea, contenteditable, shadow DOM). Exported from src/traits/typing-context.ts.
  • <n-avatar-group> — CSS-only container for overlapping avatar stacks with reverse flex order and outline ring.

Updated Updates

  • <n-field> — gap attribute (none, tight, relaxed) and --n-field-gap custom property for controlling label-to-input spacing.
  • PresentController — dark backdrop (rgba(0,0,0,0.75)), [presented] attribute on host element, inline SVG close icon (no icon registry dependency).
  • ShortcutController — uses isTypingContext() to suppress shortcuts when typing in input fields.

Sub-Packages

  • @nonoun/native-a2ui — chip-toggled multi-panel workbench layout (JSON-IN, JSON-OUT, HTML, CSS, JS, COMPONENTS), per-pane resize controllers, CodeMirror editors for JS and UI panels.
  • @nonoun/native-chat — message action buttons, feed virtualization, partial stream rendering, transport status callbacks, panel API improvements.
  • @nonoun/native-playground — layout and styling updates for panel consistency.
  • @nonoun/native-editor — layout improvements.

0.7.4 — March 2026

New New Features

  • <n-table> — cols attribute sets grid-template-columns declaratively (e.g., cols="auto auto 1fr").

Updated Fixes

  • <n-table> — sticky-header added to observedAttributes so it can be toggled dynamically after element setup.

0.7.3 — March 2026

New New Features

  • ShortcutController — keyboard shortcut primitive with combo-string parsing ("mod+k", "shift+?", "escape"), editable target filtering, conditional when() guards, and global/scoped modes.
  • shortcutable trait adapter — declarative keyboard shortcuts via <n-controller traits="shortcutable"> with JSON shortcuts attribute.

Updated Fixes

  • <n-controller> — fixed double #apply() and leaked MutationObserver during CE upgrade after adoptNode + replaceWith (View Transitions context).

0.7.2 — March 2026

New New Features

  • <n-input> — formatting="code" attribute enables inline code formatting (backtick wrapping via Cmd/Ctrl+E).
  • SlashCommandController — Tab-to-select: pressing Tab with 2+ character query selects the closest matching command.
  • SlashCommandController — visible styled description spans in command popover options.

Updated Updates

  • Extracted shared formatting utilities into src/core/formatting.ts — reused by both <n-input> and <n-textarea>.

0.7.0 — March 2026

New New Features

  • <n-text> — CSS-only utility element for styled text blocks (muted, strong, sizes, truncate, spacing).
  • SlashCommandController — detects / prefix in inputs, shows filtered command listbox popover.
  • <n-panel> [fade] attribute — fades top/bottom edges when content overflows.
  • <n-panel> [scrollable] attribute — opt-in overflow scrolling (replaces implicit overflow).

Updated Updates

  • <n-toolbar> — overflow priority (overflow-priority), pin (overflow-pin), and diagnostics (native:toolbar-overflow event).
  • <n-header> — [truncate] attribute for label text truncation with ellipsis.
  • <n-textarea> — inline formatting support (formatting="code bold italic").
  • ResizeController — corner resize handles for diagonal resizing.

Breaking Changes

  • <n-panel> overflow is now opt-in via [scrollable]. Panels that relied on implicit overflow: auto must add the attribute.

  • Bumped all package versions to 0.6.6.
